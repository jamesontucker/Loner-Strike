    Why this exists

    I still play Counter-Strike 1.6 and Condition Zero.
    Mostly late at night, mostly against bots.

    The problem is the bots. They aren't very fun to play with. And the custom stuff, Zombie Plague, Warcraft 3, Gun Game, means digging through forum threads from 2009, fixing config files, and then finding out half the mods don't even notice bots exist.

    So I fixed it for myself. Bots that feel like the regulars on an old community server. The old mods, patched to work with them. A panel so I never have to open another .cfg file. And on the rare night a friend wants to play, they can join in a click.

    It turned out pretty good, so here it is. It's free, because none of it would exist without the people who made these mods in the first place.

    Bots that play like people

    The game's own bots react instantly, never miss and move as one squad. Loner-Strike rebuilds how they think, so a server full of bots feels like a server full of people.

    • Each bot has its own personality, skill and habits
    • They chat, banter and rage, and answer you in chat or on your mic: "rush b", "flash for me", "someone buy me an awp"
    • Ts take sites together; CTs hold them and retake
    • Lone wolves in a pub, a team in a match
    • Regulars with clan tags who remember you

      How the bots play

      The game's own bots walk the same lines, freeze to reload and backpedal in every fight. Loner-Strike doesn't just tweak their settings: it ships its own bot brain, a rework of the game's bot code that changes how they see, aim, move and plan.

      • They aim like a hand on a mouse. Still most of the time, then a quick flick that lands a touch off and gets corrected. Good players tap; worse ones spray and run.
      • They react like people. A human moment before they fire, longer for a newbie than a veteran.
      • They move like players. Their own routes, quiet near enemies, peeking corners and stopping to shoot.
      • They take sites together. Ts gather out of sight and go in at once. CTs hold the sites and run back to retake.
      • They have habits. Spawn hops, freeze-time flicks, reloading after every kill. A bot that keeps dying gets tilted; the best bunnyhop.
      • They play the mode. Run and gun in Deathmatch and Gun Game, lone wolves in a pub, a team in a 5v5.

        Questions

        Is it really free?

        Yes. The code is open source (GPL-3) and every release is on GitHub. Paying is optional and gets you the same thing.

        Do I need to own Counter-Strike?

        Yes. Loner-Strike adds to the game you already have on Steam: Counter-Strike 1.6, Condition Zero, or both.

        Does it work on a Mac?

        Yes, but not with the Mac version of Counter-Strike, which can't run mods. Install Windows Steam and the game in CrossOver (paid, with a free trial), and Loner-Strike finds it there. With Parallels (a Windows virtual machine), install the Windows version of Loner-Strike inside Windows.

        Windows says it protected my PC

        That's SmartScreen, which warns about apps that aren't widely downloaded yet. Click More info, then Run anyway. The code is open on GitHub if you want to check what it does.

        Will it mess up my game?

        Every file it changes is backed up first. Remove one mode, or all of Loner-Strike, from the app and your game goes back the way it was. The mods only run in games you host.

        Do my friends need it too?

        No. They only need Counter-Strike. They join your game like any other server, and it sends them the maps.

        Do I need a server to play with friends?

        No. Your own game can host them while you play; Loner-Strike has seven ways for friends to connect. A dedicated server is for one that stays up when you're not playing.

        What does a server cost?

        On your own computer, nothing. A rented Linux machine runs from free (Oracle's free tier, when it has room) to a small monthly plan for a server with 20 to 32 players and bots. The guide covers where to rent one and what size to pick.

        Can people join without Loner-Strike?

        Yes. Anyone with Counter-Strike 1.6 (or Condition Zero, for a CZ server) joins like any other server, and it sends them the maps and sounds they need.

        Who made the mods?

        Their original authors: the AMX Mod X, Metamod and ReGameDLL teams, and the community modders behind Zombie Plague, Warcraft 3, SuperHero and the rest. Loner-Strike sets them up and patches them for bots. Everyone is credited on GitHub.
