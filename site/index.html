Bots that play like people

The game's own bots react instantly and aim perfectly. Loner-Strike gives them human reaction times and imperfect aim, with skill levels from casual up to players who bunnyhop.

  • A regular cast of bot names and clan tags, so the server has familiar faces
  • Bots learn new maps by themselves
  • Thousands of maps from GameBanana, one click each

Play with friends

Set a server name and password, then send friends an invite. There are seven ways for them to connect, from a LAN party in the same room to playit.gg, Tailscale, your router or Hamachi.

  • Control everything from your phone by scanning a QR code
  • Admins, VIPs and bans
  • A custom welcome page for people who join

Dedicated servers

Optional, for an always-on server: Loner-Strike downloads Valve's free dedicated server, sets it up like your game and runs it. Each server has its own modes, maps, admins, VIP perks and console. You can also bring in a server you already run.

The app includes a guide to free and low-cost hosting, and how big a server needs to be.

    Questions

    Is it really free?

    Yes. The code is open source (GPL-3) and every release is on GitHub. Paying is optional and gets you the same thing.

    Do I need to own Counter-Strike?

    Yes. Loner-Strike adds to the game you already have on Steam: Counter-Strike 1.6, Condition Zero, or both.

    Does it work on a Mac?

    Yes, but not with the Mac version of Counter-Strike, which can't run mods. Install Windows Steam and the game in one of these, and Loner-Strike finds it:

    CrossOver (paid, with a free trial) is the most reliable. Whisky is free and works the same way, though it's no longer actively developed. With Parallels (a Windows virtual machine), it's just Windows: install the Windows version of Loner-Strike inside it.

    Will it mess up my game?

    Every file it changes is backed up first. Remove one mode, or all of Loner-Strike, from the app and your game goes back the way it was. The mods only run in games you host.

    Do my friends need it too?

    No. They only need Counter-Strike. They join your game like any other server, and it sends them the maps.

    Who made the mods?

    Their original authors: AMX Mod X, Metamod and ReGameDLL teams, and the community modders behind Zombie Plague, Warcraft 3, SuperHero and the rest. Loner-Strike sets them up and patches them for bots. Everyone is credited on GitHub.
