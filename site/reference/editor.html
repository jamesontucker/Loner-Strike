    Reference

    Map editor

    The map editor's 87 tools and commands, by task: what each does, where to find it and its keys.

    Keys for

    Files and projects

    Start a map, open one, save it, and bring maps in from other editors. More in the docs

    New map

    Starts a new map: an open-sky room with two spawns per team, ready to build in. If the open map has unsaved changes, it asks first.

    Where
    File›New mapStart screen›New map
    Keys
    Ctrl+Alt+N⌥⌘NHammer-style: Ctrl+N⌘N

    Open a project

    Opens a map you saved as a project (.lsmap), with its groups, hidden things and settings as you left them.

    Where
    File›Open a project…Start screen›Open a project
    Keys
    Ctrl+O⌘O

    Good to know: Your recent maps are listed at the bottom of the File menu and on the start screen.

    Save and Save as

    Keeps the map as a project (.lsmap) with everything in it: brushes, entities, groups, hidden and locked things.

    • SaveSaves over the project.
      File›SaveEditor bar›SaveCtrl+S⌘S
    • Save as…Saves under a new name or in a new place.
      File›Save as…Ctrl+Shift+S⇧⌘S
    In the docs

    Autosave and recovery

    The editor saves your work on its own every 3 minutes, and each save keeps the one before. After a crash, the start screen offers the work it kept.

    Where
    Start screen›Recover itStart screen›Throw it away

    Good to know: Went to the start screen by mistake? Back to (your map's name) takes you straight back.

    Import a .map

    Opens a .map from TrenchBroom, Hammer, J.A.C.K. or any GoldSrc editor. TrenchBroom's groups and layers come in as groups.

    Where
    File›Import a .map…Start screen›Import a .map…
    In the docs

    Import from Hammer or J.A.C.K.

    Opens a Hammer .rmf or a J.A.C.K. .jmf file, with its brushes, entities, groups and visgroups.

    Where
    File›Import a Hammer .rmf or J.A.C.K. .jmf…Start screen›Import from Hammer / J.A.C.K.
    In the docs

    Export a .map

    Writes the map as a Valve 220 .map with its texture list, for any GoldSrc compiler or to keep working in TrenchBroom.

    Where
    File›Export a .map…
    Keys
    Ctrl+E⌘E
    In the docs

    Project files

    Lists every file the map uses (models, sprites, sounds and texture files) and where each one is. Copy them into the game or next to the project, or let Find missing files… search a folder you pick.

    Where
    File›Project filesView›Panel: Project

    Good to know: The game won't load a map whose models or sprites are missing, so check here before you share it.

    In the docs

    Map and settings

    Settings that belong to the whole map, and lists of what's in it. More in the docs

    Map properties

    Sets what the whole map is like: its title, the sky and how far players can see, the base light and the sun, the buying and bomb rules, and which texture files (WADs) it uses.

    Where
    Map›Map properties…File›Map properties…Inspect panel, with nothing picked›Map properties…

    Good to know: With nothing picked, Inspect shows the sky and the texture files too.

    worldspawn

    Entity definitions

    Adds a mod's own entity file (FGD) so its entities show up in the entity list with their keys, or goes back to Loner-Strike's own list.

    Where
    Map›Map properties…›Entity definitions
    • Add your own FGD…Adds a mod's FGD next to ours.
    • Use ours onlyRemoves the added ones.
    In the docs

    Map information

    Counts what's in the map (brushes, faces and entities) and lists the textures and texture files in use.

    Where
    Map›Map information…

    Entity report

    Lists every entity in the map. Filter by name or type, tick several to pick or delete them together, or double-click one to fly to it.

    Where
    Map›Entity report…Inspect panel, with nothing picked›Entity report…

    Building

    The tools on the left of the views, and the commands that change the shape of brushes. More in the docs

    Select

    Click to pick a brush or entity. Drag a face of something picked to push or pull it, or drag across empty space to pick everything in a box.

    Where
    Tools›Select toolTool rail
    Keys
    QHammer-style: Shift+S⇧S

    Good to know: Esc lets go of what's picked. The tool options set whether a box picks what it touches or only what's fully inside.

    Move, Rotate and Scale

    Drag the handles in the views to move, turn or stretch what's picked. Hold Shift as you start a move to drag a copy instead.

    Where
    Tool rail
    • MoveDrag the arrows.
      Tools›Move toolW
    • RotateDrag the rings; it turns in 15° steps.
      Tools›Rotate toolETrenchBroom-style: R
    • ScaleDrag the handles to stretch.
      Tools›Scale toolRTrenchBroom-style: T

    Vertex

    Drag a corner (yellow), an edge (blue) or a face (purple) of a picked brush to reshape it. The brush always stays convex.

    Where
    Tools›Vertex toolTool rail
    Keys
    VHammer-style: Shift+V⇧V

    Good to know: Shift-click picks several corners, the arrow keys nudge them, and Merge corners joins them into one.

    Box

    Drag on the floor, or on top of a brush, to draw a box brush. Its height is in the tool options above the view.

    Where
    Tools›Box toolTool rail
    Keys
    BHammer-style: Shift+B⇧B

    Shape

    Draws a cylinder, wedge, spike, cone, sphere, arch or torus. Pick the kind and how many sides above the view, then drag.

    Where
    Tools›Shape toolTool rail
    Keys
    C

    Good to know: Preview… shows the shape before you draw it.

    Clip

    Cuts what's picked along a line: click two points to place the cut, Tab chooses which side stays (or both), and Enter cuts.

    Where
    Tools›Clip toolTool rail
    Keys
    XHammer-style: Shift+X⇧XTrenchBroom-style: C

    Measure

    Drag between two points to see the distance between them, in game units.

    Where
    Tools›Measure toolTool rail
    Keys
    M

    Hollow

    Turns a solid brush into a room: walls of the thickness set in Inspect, with the inside empty.

    Where
    Edit›HollowInspect panel›Hollow
    Keys
    Ctrl+H⌘H

    Carve

    Cuts the picked brush out of every brush it overlaps, like cutting a doorway through a wall. The brush you carve with stays.

    Where
    Edit›CarveInspect panel›Carve
    Keys
    None in our key setHammer-style: Ctrl+Shift+C⇧⌘C

    Merge

    Joins the picked brushes into one convex brush. If they don't make a convex shape together, the new brush fills the gaps between them.

    Where
    Edit›MergeInspect panel›Merge

    Snap to grid

    Rounds every corner of the picked brushes to the grid and rebuilds them, to fix small gaps and corners just off the grid.

    Where
    Edit›Snap to gridInspect panel›Snap
    Keys
    Ctrl+B⌘B

    Flip

    Mirrors what's picked along the X, Y or Z axis, around its middle.

    Where
    Inspect panel›Flip
    • Flip along X
      Edit›Flip along XNone in our key setHammer-style: Ctrl+L⌘LTrenchBroom-style: Ctrl+F⌘F
    • Flip along Y
      Edit›Flip along Y
    • Flip along Z
      Edit›Flip along ZNone in our key setHammer-style: Ctrl+I⌘ITrenchBroom-style: Ctrl+Alt+F⌥⌘F

    Turn 90°

    Turns what's picked a quarter turn around the X, Y or Z axis, around its middle.

    Where
    Inspect panel›Turn
    • Turn 90° around X
      Edit›Turn 90° around X
    • Turn 90° around Y
      Edit›Turn 90° around Y
    • Turn 90° around Z
      Edit›Turn 90° around Z

    Transform

    Moves, turns or stretches what's picked by exact numbers instead of by dragging.

    Where
    Edit›Transform…
    Keys
    Ctrl+M⌘M

    Line up and spread out

    Lines up two or more picked things on their low, middle or high side along an axis, or spreads three or more out evenly.

    Where
    Edit›Transform…›Line upHelp›Find a command…

    Nudge

    Moves what's picked one grid step at a time: the arrow keys across, Page Up and Page Down up and down. Each nudge can be undone.

    Where
    Any view, with something picked
    Keys
    Arrow keys or Page Up or Page Down

    Editing

    Undo, copy, duplicate and group: the Edit menu's everyday commands. More in the docs

    Undo and Redo

    Steps back through your changes, and forward again.

    • UndoTakes back the last change.
      Edit›UndoCtrl+Z⌘Z
    • RedoPuts it back.
      Edit›RedoCtrl+Shift+Z⇧⌘Z or Ctrl+Y⌘Y

    Undo history

    Lists every change you've made. Click a step to go back to it, or click a later one to redo up to there.

    Where
    Edit›Undo historyView›Panel: History

    Cut, Copy and Paste

    Moves or copies what's picked through the clipboard.

    • CutCopies it and takes it out of the map.
      Edit›CutCtrl+X⌘X
    • CopyCopies it.
      Edit›CopyCtrl+C⌘C
    • PastePuts the copy in the map.
      Edit›PasteCtrl+V⌘V

    Good to know: The clipboard holds .map text, so you can copy between maps and to or from other editors.

    Duplicate

    Makes a copy of what's picked and picks the copy. Targets get new names so the copy works on its own.

    • DuplicateA copy one grid step over.
      Edit›DuplicateInspect panel›DuplicateOutline panel›right-click›DuplicateCtrl+D⌘D
    • Duplicate in placeA copy right on top, to move next.
      Edit›Duplicate in placeCtrl+Shift+D⇧⌘D
    • Duplicate (keep names)A copy with the same target names.
      Help›Find a command…

    Paste special

    Makes several copies at once: in a row, as stairs, in a ring or in a spiral, each a set distance and turn from the last.

    Where
    Edit›Paste special…Inspect panel›Paste special…
    Keys
    Ctrl+Shift+V⇧⌘V

    Delete

    Takes what's picked out of the map.

    Where
    Edit›DeleteInspect panel›Delete
    Keys
    Delete or Backspace

    Group and Ungroup

    Keeps brushes and entities together, so a click picks them all.

    Where
    Inspect panel›GroupOutline panel›right-click
    • GroupMakes what's picked one group.
      Edit›GroupCtrl+G⌘G
    • UngroupSplits it again.
      Edit›UngroupCtrl+Shift+G⇧⌘GHammer-style: Ctrl+U⌘U

    Good to know: Select › Clicks pick single objects lets you pick inside a group without ungrouping it.

    Tie to entity

    Makes the picked brushes one brush entity: a func_wall at first, then pick what it should be (a door, a breakable, a trigger…) in Inspect.

    Where
    Edit›Tie to entityInspect panel›Tie
    Keys
    Ctrl+T⌘T
    func_wallfunc_doorfunc_breakable

    Move to world

    Turns brush entities back into plain world brushes.

    Where
    Edit›Move to worldInspect panel›Move to world
    Keys
    None in our key setHammer-style: Ctrl+Shift+W⇧⌘W

    Replace with entity or prefab

    Swaps each picked thing for another entity or for a prefab, in the same place.

    Where
    Edit›Replace with entity or prefab…

    Selecting and hiding

    Pick things by what they are, find them by name or number, and hide or lock what's in the way. More in the docs

    Select all, none or the rest

    Picks everything you can see, nothing, or everything that isn't picked now.

    • Select all
      Select›Select allCtrl+A⌘A
    • Select none
      Select›Select noneCtrl+Shift+A⇧⌘A
    • Invert selection
      Select›Invert selectionCtrl+I⌘I

    Good to know: Hidden and locked things are left out.

    Select the same or what's nearby

    Grows the selection from what's picked now.

    • Select same textureEvery face with the picked texture.
      Select›Select same texture
    • Select same typeEvery entity of the picked kind (or every world brush).
      Select›Select same type
    • Select same nameEvery entity with the picked one's name (targetname).
      Select›Select same name
    • Select touchingEverything touching what's picked.
      Select›Select touching
    • Select insideEverything wholly inside the selection's box.
      Select›Select inside

    Go to brush or entity number

    Picks a brush or entity by its number, the way the compiler names them in its messages (Entity 3, Brush 12), and flies to it.

    Where
    Select›Go to brush or entity number…
    Keys
    Ctrl+J⌘JHammer-style: Ctrl+Shift+G⇧⌘G
    In the docs

    Find and replace

    Finds textures, entity types, key names or values across the map and replaces them, in the whole map or only in what's picked. Pick them selects everything it found.

    Where
    Edit›Find and replace…
    Keys
    Ctrl+F⌘FHammer-style: Ctrl+Shift+F⇧⌘F

    Outline

    Lists everything in the map by name and type. Search it, sort it, hide or lock a row, and double-click one to fly to it.

    Where
    Map›OutlineView›Panel: Outline

    Hide and show

    Hides things to work on what's behind them; hidden things stay in the map and still compile.

    Where
    Inspect panel›HideOutline panel (per row)
    • HideHides what's picked.
      Select›HideHTrenchBroom-style: Ctrl+H⌘H
    • Hide everything elseLeaves only what's picked.
      Select›Hide everything elseShift+H⇧HTrenchBroom-style: Ctrl+I⌘I
    • Show everythingBrings it all back.
      Select›Show everythingUTrenchBroom-style: Ctrl+Shift+H⇧⌘H
    • Hide all point entitiesSpawns, lights, sounds and the like.
      Select›Hide all point entities
    • Hide triggers and zonesTriggers, buy zones, bomb sites and rescue zones.
      Select›Hide triggers and zones
    • Hide world brushes
      Select›Hide world brushes

    Lock

    Locked things can't be picked by a click, so you can't move them by mistake.

    Where
    Outline panel (per row)
    • LockLocks what's picked.
      Select›LockL
    • Unlock everything
      Select›Unlock everythingShift+L⇧L

    Visgroups

    Named sets of brushes and entities you can show and hide together, at the top of the Outline.

    Where
    Outline panel›New visgroup

    What a click picks

    Sets whether a click on a grouped brush picks the whole group or just the one object.

    Where
    Tool options (above the views)›Pick groups / Pick objects / Pick brushes
    • Clicks pick whole groups
      Select›Clicks pick whole groups
    • Clicks pick single objects
      Select›Clicks pick single objects

    Good to know: Pick brushes (in the tool options) picks single brushes even inside a brush entity, like Hammer's Solids.

    Texturing

    Choose textures, paint them on and line them up. More in the docs

    Textures

    Shows the textures in the map's texture files. Click one to make it the current texture, or double-click to paint it on what's picked.

    Where
    Map›TexturesView›Panel: Textures

    Good to know: Add texture files (WADs) in Map properties.

    Apply the current texture

    Paints the current texture on the picked faces, or on every face of the picked brushes.

    Where
    Edit›Apply the current texture
    Keys
    Shift+T⇧T

    Texture tool

    Click a face to pick it (Shift adds more), drag it to slide the texture, and drag the handles to turn or stretch it. Alt-click picks up a face's texture.

    Where
    Tools›Texture toolTool rail
    Keys
    THammer-style: Shift+A⇧A

    Good to know: In the 3D view, right-click paints the current texture on a face, and Alt-right-click paints it and carries the alignment round the corner, like Hammer.

    Face sheet

    With faces picked, Inspect shows how their texture lies: shift, scale and turn it, Fit or Justify it, align it to the world or to the face (good for slopes), or pick up a face's texture to reuse.

    Where
    Inspect panel, with faces picked

    Texture lock

    Keeps textures in place on the brushes as you move or turn them. Scale lock, beside it, decides what stretching a brush does: on, the textures stretch with it; off, they keep their size and repeat.

    Where
    View›Texture lock on / offTool options (above the views)›Texture lock, Scale lock
    Keys
    None in our key setHammer-style: Shift+L⇧L

    Checking and leaks

    Find what would stop the map compiling or loading, before it does. More in the docs

    Checks

    Finds broken brushes, missing textures, spawns and files, broken targets, limits, and what a mode still needs, as you build. Click a problem to go to it; most have a one-click fix.

    Where
    Map›Check the mapView›Panel: Checks

    Leaks

    When a compile finds a leak (a gap to the void), a red line runs from an entity out through the hole, and a bar names the brush beside the gap.

    • Go to leakFlies along the line to the hole and picks the brush beside it.
      Map›Go to leakLeak bar›Go to leak
    • Show or hide the leak line
      Map›Show or hide the leak lineLeak bar›Hide line
    • Load pointfile…Loads a leak line (.lin or .pts) from another compile.
      Map›Load pointfile…

    Good to know: Close the gap with a brush and compile again. The leak bar also has Pick brushes at the hole and Forget it.

    In the docs

    Budget

    Shows how close the map is to the engine's limits (models, sounds, entities, textures and, after a compile, the map's own numbers). Click a bar for what uses the most.

    Where
    View›BudgetView›Panel: Budget

    Good to know: Green has room, yellow is over 75%, red over 90%. Playtest and Publish ask first when a bar is red.

    In the docs
