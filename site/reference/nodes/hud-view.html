HUD & View

Game Mode Studio's HUD & View nodes (12): what each does, its inputs and outputs, settings, limits and related nodes.

Made from the app's own catalog (nodes.json, nodehelp.json, limits.ts), so it always matches the app.

Hide HUD Parts #

Hides parts of a player's HUD (or everyone's): the crosshair, money, the round timer, the radar with health and armor (one switch in the game), the weapon and ammo panel, the flashlight icon. Nothing ticked shows it all again. It stays through the game redrawing the HUD; Back to normal on death/respawn ends it there.

Uses the game's own HUD switches (HideWeapon), so it costs nothing while it's on. The radar, health and armor are one switch in Counter-Strike. A spectator's own HUD isn't touched.

Inputs

Run Flow
Runs this node.
Player (empty: everyone) Player
Player (empty: everyone): a player. Optional.

Outputs

Then Flow
Goes on when it's done.

Settings

Crosshair
On or off. Default: true.
Money
On or off. Default: false.
Round timer
On or off. Default: false.
Radar, health and armor
On or off. Default: false.
Weapon and ammo panel
On or off. Default: false.
Flashlight icon
On or off. Default: false.
Back to normal on death/respawn
On or off. Default: true.

Related: Set Field of View, Show HUD Text, Set Weapon View Model

Set Field of View #

How wide a player sees (or everyone): 90 is normal, less zooms in, more is a fish-eye. A sniper scope still zooms and comes back to this. Back to normal on death/respawn puts 90 back there.

Scopes still work: a sniper zooms in and goes back to this field of view. Very wide or very narrow views can make people feel sick; keep it between 60 and 120 for long play.

Inputs

Run Flow
Runs this node.
Player (empty: everyone) Player
Player (empty: everyone): a player. Optional.
Degrees Number
Degrees: a number. Leave it empty to use the setting.

Outputs

Then Flow
Goes on when it's done.

Settings

Degrees
A number from 10 to 170. A wire into the pin of the same name is used instead. Default: 90. From 10 up to 170.
Back to normal on death/respawn
On or off. Default: true.

Related: Hide HUD Parts, Set Weapon View Model, Flashlight

Set Weapon View Model #

The model a player sees in their own hands (models/v_...mdl) for the weapon in hand or a chosen weapon, kept whenever they take it out again; also, if set, the model others see them hold (models/p_...mdl). Back to normal model puts the game's own back. Your own models are loaded with the map and go with the mode when you publish it.

The model must be a file under models/ (the game's own, like models/v_knife.mdl, or your own). A file that isn't there is left out and the weapon keeps its own model. Only the look changes: damage, speed and sounds are the weapon's.

Inputs

Run Flow
Runs this node.
Player Player
The player. Needs a wire.

Outputs

Then Flow
Goes on when it's done.

Settings

Weapon
Pick one: The one in hand, Knife, AK-47, M4A1, AWP, Scout, FAMAS, Galil, AUG, SG 552, MP5, P90…. Default: current. Choices: The one in hand, Knife, AK-47, M4A1, AWP, Scout, FAMAS, Galil, AUG, SG 552, MP5, P90, UMP 45, MAC-10, TMP, M3 shotgun, XM1014 shotgun, M249, Desert Eagle, USP, Glock, P228, Five-SeveN, Dual Elites, HE grenade, Flashbang, Smoke grenade.
View model
A file in the game folder, like models/w_c4.mdl or ambience/thunder_clap.wav. Default: models/v_knife.mdl.
Model others see (empty: unchanged)
A file in the game folder, like models/w_c4.mdl or ambience/thunder_clap.wav.
Back to normal model
On or off. Default: false.

Careful: Each model the mode uses is loaded with the map (the game has a limit of 512 models).

Related: Set Field of View, Flashlight, Hide HUD Parts

Flashlight #

Turns a player's flashlight on or off, lets them use it or not (F), and sets its battery (0 to 100; -1 leaves it).

Don't let them use it also turns it off; Let them use it undoes that. The battery is what the HUD shows; it drains and recharges as usual.

Inputs

Run Flow
Runs this node.
Player Player
The player. Needs a wire.

Outputs

Then Flow
Goes on when it's done.

Settings

Do
Pick one: Turn it on, Turn it off, Let them use it, Don't let them use it. Default: on. Choices: Turn it on, Turn it off, Let them use it, Don't let them use it.
Battery
A number from -1 to 100. Default: -1. From -1 up to 100.

Limits: Effect messages a frame (48 by default, hosts can raise it to 160; slow above 96).

Related: Set Weapon View Model, Night Vision, Set Field of View

Silent Footsteps #

A player's footsteps make no sound (on) or sound again (off). It lasts until turned off or they leave.

Only the footstep sounds: jumping and landing still make noise, and bots still hear players who shoot.

Scoreboard Tag #

Shows VIP, Bomb or Dead next to a player's name on everyone's scoreboard (or none: the game's own again). Only the tag: they aren't really the VIP, carrying the bomb or dead. Clear on death/respawn ends it there.

The game sends the tags again when someone dies, spawns or picks up the bomb; this one is put back on each time until it's set to None.

Goes on when it's done.

Settings

Tag
Pick one: None (the game's own), VIP, Bomb, Dead. Default: vip. Choices: None (the game's own), VIP, Bomb, Dead.
Clear on death/respawn
On or off. Default: false.

Limits: Effect messages a frame (48 by default, hosts can raise it to 160; slow above 96).

Related: Silent Footsteps, Scoreboard Team Color, Night Vision

Scoreboard Team Color #

Shows a player as a Terrorist, Counter-Terrorist or spectator in everyone's game (name color, scoreboard section) without moving them: their real team, spawns and rules stay. Real team undoes it. Side effects: the radar and name tags follow what's shown, and the player's own buy menu and team HUD do too.

Only how the player is shown changes. The game still treats them as their real team for damage, spawns, buying and winning. Everyone's radar and name tags follow the shown team, and the player's own client does too (their buy menu shows that team's guns, which they can't buy).

Inputs

Run Flow
Runs this node.
Player Player
The player. Needs a wire.

Outputs

Then Flow
Goes on when it's done.

Settings

Show as
Pick one: Terrorist, Counter-Terrorist, Spectator, Real team. Default: t. Choices: Terrorist, Counter-Terrorist, Spectator, Real team.

Limits: Effect messages a frame (48 by default, hosts can raise it to 160; slow above 96).

Careful: Players can be confused about who's on which team; say so in the mode's description.

Related: Scoreboard Tag, Force Spectate, Silent Footsteps

Force Spectate #

Makes a dead player or a spectator watch Target through their eyes, and keeps them on Target until Release (or Target leaves). A living player is refused.

The watcher sees through Target's eyes and can't switch away while it lasts. When Target dies they keep watching the body until Release or a new Target.

Inputs

Run Flow
Runs this node.
Watcher Player
Watcher: a player. Needs a wire.
Target Player
Target: a player. Optional.

Outputs

Then Flow
Goes on when it's done.

Settings

Do
Pick one: Watch Target, Release. Default: watch. Choices: Watch Target, Release.

Related: Scoreboard Team Color, Play Soundtrack, Scoreboard Tag

Play Soundtrack #

Plays a Half-Life soundtrack track for everyone or one player (the game's own music files, as a map's trigger_cdaudio does), looping if asked; or stops it. Players hear it only if their game has the soundtrack (Steam's Half-Life files do).

The tracks are the Half-Life soundtrack's, numbered as the game numbers them (2 is the first). It's the player's own music volume (MP3 volume in the options).

Default: 2. Radar Blip #

A dot on players' radar at a position or an entity (everyone's, a team's or only Viewer's), or takes it off. Hostage dots: four slots, each one dot (a hostage map's own hostages share the game's dots). Bomb dot: one, the dropped-bomb dot (the game moves it when the real bomb drops or is picked up).

The radar only has room for a few dots: four hostage dots (slots 1 to 4) and one dropped-bomb dot. On a hostage map the real hostages use the same kind of dots. The game redraws the bomb dot when the real bomb is dropped or picked up.

Dot
Pick one: Hostage dot, Bomb dot. Default: hostage. Choices: Hostage dot, Bomb dot.
Slot (hostage dots)
Pick one: 1, 2, 3, 4. Default: 1. Choices: 1, 2, 3, 4.
Seen by
Pick one: Everyone, Terrorists, Counter-Terrorists, Only Viewer. Default: all. Choices: Everyone, Terrorists, Counter-Terrorists, Only Viewer.

Limits: Effect messages a frame (48 by default, hosts can raise it to 160; slow above 96).

Related: Show Team Score, Play Soundtrack, Force Spectate
