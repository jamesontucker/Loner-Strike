    Fires a model or sprite (loaded with the map). Where from: At position, else At entity (a player's eyes) moved by Local offset along its own forward, right and up (16 forward when nothing is wired there), else the owner's eyes. Which way: Direction, else Rotation, else the way At entity (or the owner) faces when Face the way At entity faces is on, turned by Rotation offset; Velocity, when wired, sets the motion outright. Gravity 0 flies straight; 1 falls like a grenade. Bounces: off walls before it stops. Damage: to what it hits, or everything within Radius (less further out with Falloff). Kills count for the owner. On Hit runs later for this projectile only, with what it hit (each bounce too); On Expired when its time runs out. 64 fly at most; a new round clears them. If the spot is blocked (Unreal's Spawn Collision Handling): Always spawn, ignore collisions (Unreal's Always Spawn: it may get stuck); Try a nearby spot, but always spawn (Adjust If Possible But Always Spawn); Try a nearby spot, don't spawn if still blocked (Adjust If Possible But Don't Spawn If Colliding); Don't spawn if blocked (Do Not Spawn); or Retry every N seconds up to M tries (0: until it's clear). Nearby means within Max distance; Moved says it was moved. Outputs: Then goes on right away; Spawned once it exists, Failed once it gives up (Retry can make these come later); Entity, Success, Moved and Failure Reason (Blocked, Out of entity slots, Limit reached, Missing file, Retries used up, Bad input) let you try a fallback, like another spot.

    Settings (18)
    Model or sprite
    Picked from this mode's own pieces. A wire into the pin of the same name is used instead. Default: models/w_hegrenade.mdl.
    Face the way At entity faces
    On or off. Default: true.
    Speed
    A number from 1 to 5000. A wire into the pin of the same name is used instead. Default: 1000.
    Scale
    A number from 0.05 to 4. A wire into the pin of the same name is used instead. Default: 1.
    Gravity
    A number from 0 to 4. Default: 0.
    Lifetime (seconds)
    A number from 0.1 to 60. Default: 5.
    Bounces
    A number from 0 to 10. Default: 0.
    Damage
    A number from 0 to 5000. A wire into the pin of the same name is used instead. Default: 0.
    Radius
    A number from 0 to 2000. Default: 0.
    Falloff
    On or off. Default: true.
    Explosion
    On or off. Default: false.
    Trail
    On or off. Default: false.
    Spin
    On or off. Default: false.
    Dangerous to bots
    On or off. Default: false.
    If the spot is blocked
    Pick one: Always spawn, ignore collisions, Try a nearby spot, but always spawn, Try a nearby spot, don't spawn if still blocked, Don't spawn if blocked, Retry every N seconds up to M tries. Default: force.
    Max distance for a nearby spot
    A number from 16 to 1024. Default: 128.
    Retry every (seconds)
    A number from 0.1 to 60. Default: 1.
    Retry tries (0: until clear)
    A number from 0 to 1000. Default: 10.
    Limits (2)
    Projectiles at once
    64 by default; hosts can raise it to 512. Above 128 the server may slow down.
    Effect messages a frame
    48 by default; hosts can raise it to 160. Above 96 the server may slow down.
    Notes (1)

    Needs Loner-Strike's components plugin, which comes with the app.
