    Pin types

    The 37 types a Game Mode Studio pin can have: what each is, what it plugs into and how to cast to it.

    Every pin has a type, shown by its color and shape: a square for a file, a grid for an array, a diamond for a map, a letter for an entity handle, # for a whole number. A wire joins pins of the same type, or a narrower type into a wider one (a Creature into an Entity pin); going the other way takes a cast (As Creature). The Types and casting guide walks through it.
