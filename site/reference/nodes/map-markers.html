    Find Marker

    valuemarker.find
    Find Marker
    • Which
    • Marker
    • Position
    • Found

    The map's marker of this kind (1st, 2nd... in the map's order; a path's spots in their order), where it is, and whether the map has it.

    Inputs (1)
    Which Number
    Which: a number. Leave it empty to use the setting.
    Outputs (3)
    Marker Entity
    Marker: an entity (a thing in the map).
    Position Vector
    The position.
    Found Yes/No
    Found: yes or no.
    Settings (2)
    Marker
    Picked from this mode's own pieces.
    Which (1st, 2nd...)
    A number from 1 to 128. A wire into the pin of the same name is used instead. Default: 1.
