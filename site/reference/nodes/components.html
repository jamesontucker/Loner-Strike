                                    Create Component

                                    actioncomp.create
                                    Create Component
                                    • At entity
                                    • At position
                                    • Local offset (forward, right, up)
                                    • Rotation (pitch, yaw, roll)
                                    • Rotation offset
                                    • EntityK
                                    • Spawned
                                    • Failed
                                    • Success
                                    • Moved
                                    • Failure reason

                                    Makes a component at an entity (wired into At, or the one with this name), with keys like radius=160 capture_secs=8. If the spot is blocked (Unreal's Spawn Collision Handling): Always spawn, ignore collisions (Unreal's Always Spawn: it may get stuck); Try a nearby spot, but always spawn (Adjust If Possible But Always Spawn); Try a nearby spot, don't spawn if still blocked (Adjust If Possible But Don't Spawn If Colliding); Don't spawn if blocked (Do Not Spawn); or Retry every N seconds up to M tries (0: until it's clear). Nearby means within Max distance; Moved says it was moved. Outputs: Then goes on right away; Spawned once it exists, Failed once it gives up (Retry can make these come later); Entity, Success, Moved and Failure Reason (Blocked, Out of entity slots, Limit reached, Missing file, Retries used up, Bad input) let you try a fallback, like another spot. Where: At entity (its spot, moved by Local offset along its own forward, right and up; it faces the way the entity does if Face the way At entity faces is on, turned by Rotation offset) or At position. Rotation (pitch, yaw, roll) sets the facing outright (no Velocity or Scale: a component is a zone).

                                    Inputs (6)
                                    Run Flow
                                    Runs this node.
                                    At entity Entity
                                    At entity: an entity (a thing in the map). Optional.
                                    At position Vector
                                    At position: a position or direction (X, Y, Z). Optional.
                                    Local offset (forward, right, up) Vector
                                    Local offset (forward, right, up): a position or direction (X, Y, Z). Optional.
                                    Rotation (pitch, yaw, roll) Vector
                                    Rotation (pitch, yaw, roll): a position or direction (X, Y, Z). Optional.
                                    Rotation offset Vector
                                    Rotation offset: a position or direction (X, Y, Z). Optional.
                                    Outputs (7)
                                    Then Flow
                                    Goes on when it's done.
                                    EntityK Component
                                    Entity: a component entity (a Component handle).
                                    Spawned Flow
                                    Runs on Spawned.
                                    Failed Flow
                                    Runs on Failed.
                                    Success Yes/No
                                    Success: yes or no.
                                    Moved Yes/No
                                    Moved: yes or no.
                                    Failure reason Spawn Failure
                                    Failure reason: why the spawn failed (none, blocked, out of entity slots...). Values: None, Blocked, Out of entity slots, Limit reached, Missing file, Retries used up, Bad input.
                                    Settings (8)
                                    Component
                                    Pick one: Capture point, Safe zone, Shrinking zone, Damage zone, Loot container, Weapon spawner, Supply drop, Wave spawner, Extraction point, Checkpoint, Trap, Respawn point…. Default: ls_capture_point.
                                    At the entity named
                                    A name, as the map or the game knows it (letters, digits, _ . -). Default: spot1.
                                    Keys
                                    Settings for the component, as key=value pairs. Up to 400.
                                    If the spot is blocked
                                    Pick one: Always spawn, ignore collisions, Try a nearby spot, but always spawn, Try a nearby spot, don't spawn if still blocked, Don't spawn if blocked, Retry every N seconds up to M tries. Default: nearby.
                                    Max distance for a nearby spot
                                    A number from 16 to 1024. Default: 128.
                                    Retry every (seconds)
                                    A number from 0.1 to 60. Default: 1.
                                    Retry tries (0: until clear)
                                    A number from 0 to 1000. Default: 10.
                                    Face the way At entity faces
                                    On or off. Default: true.
                                    Limits (1)
                                    Visible things at once
                                    128 by default; hosts can raise it to 1000. Above 200 the server may slow down.
                                    Notes (2)

                                    Needs Loner-Strike's components plugin, which comes with the app.

                                    Careful: Each component is an entity; remove the ones you're done with.

                                    Related:Find ComponentSet ZoneShrink Zone
