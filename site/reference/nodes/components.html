Create Component #

Makes a component at an entity (wired into At, or the one with this name), with keys like radius=160 capture_secs=8. Where: At entity (its spot, moved by Local offset along its own forward, right and up; it faces the way the entity does if Face the way At entity faces is on, turned by Rotation offset) or At position. Rotation (pitch, yaw, roll) sets the facing outright (no Velocity or Scale: a component is a zone).

Inputs

Run Flow
Runs this node.
At entity Entity
At entity: an entity (a thing in the map). Optional.
At position Vector
At position: a position or direction (X, Y, Z). Optional.
Local offset (forward, right, up) Vector
Local offset (forward, right, up): a position or direction (X, Y, Z). Optional.
Rotation (pitch, yaw, roll) Vector
Rotation (pitch, yaw, roll): a position or direction (X, Y, Z). Optional.
Rotation offset Vector
Rotation offset: a position or direction (X, Y, Z). Optional.

Outputs

Then Flow
Goes on when it's done.
Component Entity
Component: an entity (a thing in the map).

Settings

Component
Pick one: Capture point, Safe zone, Shrinking zone, Damage zone, Loot container, Weapon spawner, Supply drop, Wave spawner, Extraction point, Checkpoint, Trap, Respawn point…. Default: ls_capture_point. Choices: Capture point, Safe zone, Shrinking zone, Damage zone, Loot container, Weapon spawner, Supply drop, Wave spawner, Extraction point, Checkpoint, Trap, Respawn point, Shop (a counter, items=Name|price|give|what;...), Perk machine, Upgrade bench, Mystery box, NPC (model=barney name=... behavior=stand), Interactable (prompt=... once=1).
At the entity named
A name, as the map or the game knows it (letters, digits, _ . -). Default: spot1.
Keys
Settings for the component, as key=value pairs. Up to 400.
Face the way At entity faces
On or off. Default: true.

Needs Loner-Strike's components plugin, which comes with the app.

Careful: Each component is an entity; remove the ones you're done with.

Related: Find Component, Set Zone, Shrink Zone
