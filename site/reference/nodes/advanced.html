    Run Server Command

    actiongame.run_command
    Run Server Command
    • Command
    • Ran

    Runs a server console command, like sv_gravity 400 or mp_restartgame 1. Commands that touch passwords, files, plugins or quit the server are refused, and only one command at a time (no ; ). Community modes that use it show "runs server commands".

    Inputs (2)
    Run Flow
    Runs this node.
    Command Text
    Command: text. Leave it empty to use the setting.
    Outputs (2)
    Then Flow
    Goes on when it's done.
    Ran Yes/No
    Ran: yes or no.
    Settings (1)
    Command
    Text: letters, digits, spaces and plain punctuation. A wire into the pin of the same name is used instead. Default: sv_gravity 800. Up to 100.
    Notes (1)

    Careful: Only gameplay settings and a short list of safe commands are allowed; anything else is refused and the node's OK is No. A community mode that has this shows "runs server commands".

    Run AMX Command

    actiongame.amx_command
    Run AMX Command
    • Command
    • Ran

    Runs an AMX Mod X admin command (amx_slay, amx_slap...). amx_rcon, amx_cvar on passwords, plugin loading, bans and admin edits are refused.

    Inputs (2)
    Run Flow
    Runs this node.
    Command Text
    Command: text. Leave it empty to use the setting.
    Outputs (2)
    Then Flow
    Goes on when it's done.
    Ran Yes/No
    Ran: yes or no.
    Settings (1)
    Command
    Text: letters, digits, spaces and plain punctuation. A wire into the pin of the same name is used instead. Default: amx_slap @T 0. Up to 100.
    Notes (1)

    Careful: Only slap, slay, kick, say commands, map changes to real maps and allowed settings are let through. A community mode with this shows "runs AMX commands".

    Call Plugin Function

    actionamx.call
    Call Plugin Function
    • Argument 1
    • Argument 2
    • Result
    • Called

    Calls a public function in another AMX Mod X plugin (by its file, like gm_components.amxx) with up to two numbers; Result is what it returns. Community modes that use it show "calls other plugins".

    Inputs (3)
    Run Flow
    Runs this node.
    Argument 1 Number
    Argument 1: a number. Leave it empty to use the setting.
    Argument 2 Number
    Argument 2: a number. Leave it empty to use the setting.
    Outputs (3)
    Then Flow
    Goes on when it's done.
    Result Number
    Result: a number.
    Called Yes/No
    Called: yes or no.
    Settings (5)
    Plugin file
    A name, as the map or the game knows it (letters, digits, _ . -). Default: gm_components.amxx.
    Function
    A name, as the map or the game knows it (letters, digits, _ . -). Default: plugin_cfg.
    Arguments
    Pick one: None, One, Two. Default: 0.
    Argument 1
    A number from -100000 to 100000. A wire into the pin of the same name is used instead. Default: 0.
    Argument 2
    A number from -100000 to 100000. A wire into the pin of the same name is used instead. Default: 0.
    Notes (1)

    Careful: Calls into another plugin. If that plugin or function isn't there, OK is No and nothing happens. A community mode with this shows "calls other plugins".

        Draw Debug Line

        actiondebug.draw_line
        Draw Debug Line
        • From
        • To

        Draws a line from A to B for some seconds, to see where things are. Shown only while testing (Playtest and Test run); a finished mode draws nothing.

        Inputs (3)
        Run Flow
        Runs this node.
        From Vector
        From: a position or direction (X, Y, Z). Needs a wire.
        To Vector
        To: a position or direction (X, Y, Z). Needs a wire.
        Outputs (1)
        Then Flow
        Goes on when it's done.
        Settings (2)
        Color
        Pick one: Red, Green, Blue, Yellow, White, Orange, Purple. Default: red.
        Seconds
        A number from 0.1 to 60. Default: 2.
        Limits (1)
        Effect messages a frame
        48 by default; hosts can raise it to 160. Above 96 the server may slow down.
