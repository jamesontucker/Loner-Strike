      Spawn Creature

      actioncreature.spawn
      Spawn Creature
      • At entity
      • Health
      • Pay
      • At position
      • Local offset (forward, right, up)
      • Rotation (pitch, yaw, roll)
      • Rotation offset
      • Velocity
      • Scale
      • Creature

      Makes a creature of this type at an entity (wired into At, or the one with this name). Needs the Loner-Strike bot brain with creatures (the debugger says so if not). Where: At entity (its spot, moved by Local offset along its own forward, right and up; it faces the way the entity does if Face the way At entity faces is on, turned by Rotation offset) or At position. Rotation (pitch, yaw, roll) sets the facing outright; Velocity starts it moving (a still thing then falls and slides); Scale sizes models and sprites.

      Inputs (10)
      Run Flow
      Runs this node.
      At entity Entity
      At entity: an entity (a thing in the map). Optional.
      Health Number
      Health: a number. Leave it empty to use the setting.
      Pay Number
      Pay: a number. Leave it empty to use the setting.
      At position Vector
      At position: a position or direction (X, Y, Z). Optional.
      Local offset (forward, right, up) Vector
      Local offset (forward, right, up): a position or direction (X, Y, Z). Optional.
      Rotation (pitch, yaw, roll) Vector
      Rotation (pitch, yaw, roll): a position or direction (X, Y, Z). Optional.
      Rotation offset Vector
      Rotation offset: a position or direction (X, Y, Z). Optional.
      Velocity Vector
      Velocity: a position or direction (X, Y, Z). Optional.
      Scale Number
      Scale: a number. Leave it empty to use the setting.
      Outputs (2)
      Then Flow
      Goes on when it's done.
      Creature Entity
      Creature: an entity (a thing in the map).
      Settings (7)
      Type
      A name, as the map or the game knows it (letters, digits, _ . -). Default: zombie.
      At the entity named
      A name, as the map or the game knows it (letters, digits, _ . -). Default: spot1.
      Health (0: the type's own)
      A number from 0 to 100000. A wire into the pin of the same name is used instead. Default: 0.
      Tier (looks and enrage; 0 none)
      Pick one: None, 1, 2, 3. Default: 0.
      Pay its killer ($)
      A number from 0 to 16000. A wire into the pin of the same name is used instead. Default: 0.
      Face the way At entity faces
      On or off. Default: true.
      Scale
      A number from 0.05 to 10. A wire into the pin of the same name is used instead. Default: 1.
      Notes (1)

      Needs the Loner-Strike bot brain with creatures.

      eventup.on_creature_hurt
      Creature Hurt
        • Creature
        • Attacker
        • Damage

        A creature took damage (Headshot when the hit was a head). Hit Position: where a bullet or the knife struck (else its middle); Direction: which way the hit was going. Use Get Entity Transform on Creature, or Get Transform on Attacker, for where they were.

        Outputs (7)
        Then Flow
        Goes on when it's done.
        Creature Entity
        Creature: an entity (a thing in the map).
        Attacker Player
        Attacker: a player.
        Damage Number
        Damage: a number.
        Headshot Yes/No
        Headshot: yes or no.
        Hit Position Vector
        Hit Position: a position or direction (X, Y, Z).
        Direction Vector
        Direction: a position or direction (X, Y, Z).
        Notes (1)

        Needs Loner-Strike's components plugin, which comes with the app.
