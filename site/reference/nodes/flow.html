Flow

Game Mode Studio's Flow nodes (18): what each does, its inputs and outputs, settings, limits and related nodes.

Made from the app's own catalog (nodes.json, nodehelp.json, limits.ts), so it always matches the app.

For Each Player #

Runs Each once for every player who fits, then Then.

Runs Each once for every player that matches, then Then. The Player pin is the current one inside Each.

Inputs

Run Flow
Runs this node.

Outputs

Each Flow
Runs once for every item.
Player Player
The player.
Then Flow
Goes on when it's done.

Settings

Who
Pick one: Everyone in the game, Everyone alive, Everyone dead, Terrorists, Counter-Terrorists, Living Terrorists, Living Counter-Terrorists, Bots, People (not bots). Default: alive. Choices: Everyone in the game, Everyone alive, Everyone dead, Terrorists, Counter-Terrorists, Living Terrorists, Living Counter-Terrorists, Bots, People (not bots).

Cost: At most 32 players, so it's cheap. Inside a Repeat that ticks often, it adds up.

Related: For Each Entity, Pick Random Player, Pick Random Entity

For Each Entity #

Runs Each once for every entity of a kind or with a name (at most 512), then Then.

Inputs

Run Flow
Runs this node.

Outputs

Each Flow
Runs once for every item.
Entity Entity
The entity.
Then Flow
Goes on when it's done.

Settings

Which
Pick one: Of this kind (classname), With this name. Default: class. Choices: Of this kind (classname), With this name.
Kind or name
A name, as the map or the game knows it (letters, digits, _ . -). Default: ls_respawn_point.

Cost: Searches the whole map each time it runs. Fine at a round's start; in a fast Repeat it can slow the server.

Related: For Each Player, Pick Random Player, Pick Random Entity

For Loop #

Runs Loop Body once for each number from First to Last (at most 10000 times), then Completed.

Inputs

Run Flow
Runs this node.
First Number
First: a number. Leave it empty to use the setting.
Last Number
Last: a number. Leave it empty to use the setting.

Outputs

Loop Body Flow
Runs once for every step.
Index Number
Index: a number.
Completed Flow
Goes on when it's done.

Settings

First
A number from -100000 to 100000. A wire into the pin of the same name is used instead. Default: 0. From -100000 up to 100000.
Last
A number from -100000 to 100000. A wire into the pin of the same name is used instead. Default: 9. From -100000 up to 100000.

Cost: Each step runs everything wired to Body. Thousands of steps in one go can stall the server for a moment.

Related: Flip Flop, For Loop with Break, Gate

While Loop #

Runs Loop Body while the condition is true (checked each time; at most Limit times), then Completed.

Repeats Body while the condition is true. Limit stops it after that many times, so a condition that never turns false can't freeze the server.

Inputs

Run Flow
Runs this node.
Condition Yes/No
Condition: yes or no. Needs a wire.

Outputs

Loop Body Flow
Runs once for every step.
Completed Flow
Goes on when it's done.

Settings

Limit
A number from 1 to 10000. Default: 1000. From 1 up to 10000.

Careful: A loop that never ends is stopped by Limit; the Problems panel says when that happened.

Related: For Loop with Break, For Loop, Switch on Number

Multi Gate #

Each time flow comes in, goes out the next output (in order, or random); after the last it stops, or starts over with Loop. Reset starts again from Start index.

Inputs

Run Flow
Runs this node.
Reset Flow
Lets it run again.

Outputs

Out 0 Flow
Runs on Out 0.
Out 1 Flow
Runs on Out 1.

Settings

Outputs
A number from 1 to 8. Default: 3. From 1 up to 8.
Random
On or off. Default: false.
Loop
On or off. Default: false.
Start index
A number from 0 to 7. Default: 0. From 0 up to 7.

Related: Do Once Per Player, Reroute, Call Custom Event
