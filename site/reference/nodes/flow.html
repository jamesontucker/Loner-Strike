    For Each Player

    flowflow.for_each_player
    For Each Player
    • Each
    • Player
    • Then

    Runs Each once for every player who fits, then Then.

    Inputs (1)
    Run Flow
    Runs this node.
    Outputs (3)
    Each Flow
    Runs once for every item.
    Player Player
    The player.
    Then Flow
    Goes on when it's done.
    Settings (1)
    Who
    Pick one: Everyone in the game, Everyone alive, Everyone dead, Terrorists, Counter-Terrorists, Living Terrorists, Living Counter-Terrorists, Bots, People (not bots). Default: alive.
    Notes (2)

    Runs Each once for every player that matches, then Then. The Player pin is the current one inside Each.

    Cost: At most 32 players, so it's cheap. Inside a Repeat that ticks often, it adds up.

    Related:For Each EntityPick Random PlayerPick Random Entity

    flowflow.for_loop
    For Loop
    • First
    • Last
    • Loop Body
    • Index
    • Completed

    Runs Loop Body once for each number from First to Last (at most 10000 times), then Completed.

    Inputs (3)
    Run Flow
    Runs this node.
    First Number
    First: a number. Leave it empty to use the setting.
    Last Number
    Last: a number. Leave it empty to use the setting.
    Outputs (3)
    Loop Body Flow
    Runs once for every step.
    Index Number
    Index: a number.
    Completed Flow
    Goes on when it's done.
    Settings (2)
    First
    A number from -100000 to 100000. A wire into the pin of the same name is used instead. Default: 0.
    Last
    A number from -100000 to 100000. A wire into the pin of the same name is used instead. Default: 9.

    Cost: Each step runs everything wired to Body. Thousands of steps in one go can stall the server for a moment.

    While Loop

    flowflow.while
    While Loop
    • Condition
    • Loop Body
    • Completed

    Runs Loop Body while the condition is true (checked each time; at most Limit times), then Completed.

    Inputs (2)
    Run Flow
    Runs this node.
    Condition Yes/No
    Condition: yes or no. Needs a wire.
    Outputs (2)
    Loop Body Flow
    Runs once for every step.
    Completed Flow
    Goes on when it's done.
    Settings (1)
    Limit
    A number from 1 to 10000. Default: 1000.
    Notes (2)

    Repeats Body while the condition is true. Limit stops it after that many times, so a condition that never turns false can't freeze the server.

    Careful: A loop that never ends is stopped by Limit; the Problems panel says when that happened.

    Related:For Loop with BreakFor LoopSwitch on Number
