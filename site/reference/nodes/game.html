    Set Setting

    actiongame.set_cvar
    Set Setting
    • Value

    Changes one of the game's settings now.

    Inputs (2)
    Run Flow
    Runs this node.
    Value Number
    Value: a number. Leave it empty to use the setting.
    Outputs (1)
    Then Flow
    Goes on when it's done.
    Settings (2)
    Setting
    Pick one: Free for all (1 on), Friendly fire (1 on), Gravity (800 normal), Buy time (minutes), Start money, Air control (10 normal), Round time (minutes, next round), Freeze time (seconds, next round), Rounds only end when the mode says (1 on), Team balance (1 on), Most players more than the other team (0 any), Bomb for the Terrorists (1 on)…. Default: mp_freeforall.
    Value
    A number from 0 to 100000. A wire into the pin of the same name is used instead. Default: 1.
    Notes (2)

    A setting changed for the rest of the map. For settings the mode always wants, add them under This mode's Game settings instead (set every map).

    Careful: A few settings are set again by the game's own game.cfg after the mode's, so they don't stick: the bomb for the Terrorists (mp_give_player_c4) is one. Take the bomb with Remove Weapon (c4) at Round Started instead.

    Related:Use EntityCurrent Map NameNext Map

                            Remove Map Objectives

                            actiongame.remove_objectives
                            Remove Map Objectives

                            Takes the map's objectives away (tick which): buy zones, bomb sites, hostages, hostage rescue zones, VIP safety zones, escape zones. The game notices at the next round (the bomb isn't given, no hostages to save); removed buy zones don't fall back to buying at spawn. Best at Map Started.

                            Inputs (1)
                            Run Flow
                            Runs this node.
                            Outputs (1)
                            Then Flow
                            Goes on when it's done.
                            Settings (6)
                            Buy zones
                            On or off. Default: false.
                            Bomb sites
                            On or off. Default: true.
                            Hostages
                            On or off. Default: true.
                            Rescue zones
                            On or off. Default: true.
                            VIP safety zones
                            On or off. Default: true.
                            Escape zones
                            On or off. Default: true.

                              Voice Rules

                              actiongame.voice_rules
                              Voice Rules

                              Who hears whom on voice chat: everyone, only teammates, the dead only the dead and the living only the living, or only those within a distance (0: any distance, with the other rules). Spectators hear spectators. Voice Override changes it for one player; Mute Voice still mutes.

                              Inputs (1)
                              Run Flow
                              Runs this node.
                              Outputs (1)
                              Then Flow
                              Goes on when it's done.
                              Settings (2)
                              Who hears
                              Pick one: Everyone hears everyone, Teammates only, Dead with dead, alive with alive, Teammates, and dead with dead, Only within the distance. Default: team.
                              Within (units, 0: any)
                              A number from 0 to 8192. Default: 0.
                              Related:Map TypeRemove Map ObjectivesRound End Rules

                              Inputs (1)

                              Runs this node.
                              Outputs (1)
                              Then Flow
                              Goes on when it's done.
                              Settings (1)
                              Rounds don't end when
                              Pick one: (Ending as usual), A team is wiped out, Time runs out, Either (only End Round ends them). Default: elim.

                              Start Vote

                              actiongame.start_vote
                              Start Vote
                              • 1
                              • 2
                              • 3
                              • 4

                              • 6

                              • 8

                              • No votes

                              Asks everyone (or a team, or the living) a question with 2 to 8 answers for some seconds; then runs the winning answer's output, Tie, or No votes. Bots vote at random if Bots vote is on. Only one vote at a time, and never over the server's map or mode vote (then No votes runs). Vote Count reads the result.

                              Inputs (1)
                              Run Flow
                              Runs this node.
                              Outputs (11)
                              Then Flow
                              Goes on when it's done.
                              1 Flow
                              Runs on 1.
                              2 Flow
                              Runs on 2.
                              3 Flow
                              Runs on 3.
                              4 Flow
                              Runs on 4.
                              5 Flow
                              Runs on 5.
                              6 Flow
                              Runs on 6.
                              7 Flow
                              Runs on 7.
                              8 Flow
                              Runs on 8.
                              Tie Flow
                              Runs on Tie.
                              No votes Flow
                              Runs when nothing was found.
                              Settings (13)
                              Question
                              Text: letters, digits, spaces and plain punctuation. Default: Next round?. Up to 60.
                              Answers
                              A number from 2 to 8. Default: 2.
                              Answer 1
                              Text: letters, digits, spaces and plain punctuation. Default: Knives. Up to 30.
                              Answer 2
                              Text: letters, digits, spaces and plain punctuation. Default: Pistols. Up to 30.
                              Answer 3
                              Text: letters, digits, spaces and plain punctuation. Default: Rifles. Up to 30.
                              Answer 4
                              Text: letters, digits, spaces and plain punctuation. Default: Snipers. Up to 30.
                              Answer 5
                              Text: letters, digits, spaces and plain punctuation. Default: Shotguns. Up to 30.
                              Answer 6
                              Text: letters, digits, spaces and plain punctuation. Default: Grenades. Up to 30.
                              Answer 7
                              Text: letters, digits, spaces and plain punctuation. Default: Random. Up to 30.
                              Answer 8
                              Text: letters, digits, spaces and plain punctuation. Default: Normal. Up to 30.
                              Seconds
                              A number from 5 to 60. Default: 15.
                              Who votes
                              Pick one: Everyone, Terrorists, Counter-Terrorists, The living. Default: all.
                              Bots vote
                              On or off. Default: false.
