Game

Game Mode Studio's Game nodes (22): what each does, its inputs and outputs, settings, limits and related nodes.

Made from the app's own catalog (nodes.json, nodehelp.json, limits.ts), so it always matches the app.

Set Setting #

Changes one of the game's settings now.

A setting changed for the rest of the map. For settings the mode always wants, add them under This mode's Game settings instead (set every map).

Inputs

Run Flow
Runs this node.
Value Number
Value: a number. Leave it empty to use the setting.

Outputs

Then Flow
Goes on when it's done.

Settings

Setting
Pick one: Free for all (1 on), Friendly fire (1 on), Gravity (800 normal), Buy time (minutes), Start money, Air control (10 normal), Round time (minutes, next round), Freeze time (seconds, next round), Rounds only end when the mode says (1 on), Team balance (1 on), Most players more than the other team (0 any), Bomb for the Terrorists (1 on)…. Default: mp_freeforall. Choices: Free for all (1 on), Friendly fire (1 on), Gravity (800 normal), Buy time (minutes), Start money, Air control (10 normal), Round time (minutes, next round), Freeze time (seconds, next round), Rounds only end when the mode says (1 on), Team balance (1 on), Most players more than the other team (0 any), Bomb for the Terrorists (1 on), Downed players can be finished by enemies (1 on; components), A downed player's health when they can be finished (components).
Value
A number from 0 to 100000. A wire into the pin of the same name is used instead. Default: 1. From 0 up to 100000.

Careful: A few settings are set again by the game's own game.cfg after the mode's, so they don't stick: the bomb for the Terrorists (mp_give_player_c4) is one. Take the bomb with Remove Weapon (c4) at Round Started instead.

Related: Use Entity, Current Map Name, Next Map

Remove Map Objectives #

Takes the map's objectives away (tick which): buy zones, bomb sites, hostages, hostage rescue zones, VIP safety zones, escape zones. The game notices at the next round (the bomb isn't given, no hostages to save); removed buy zones don't fall back to buying at spawn. Best at Map Started.

Inputs

Run Flow
Runs this node.

Outputs

Then Flow
Goes on when it's done.

Settings

Buy zones
On or off. Default: false.
Bomb sites
On or off. Default: true.
Hostages
On or off. Default: true.
Rescue zones
On or off. Default: true.
VIP safety zones
On or off. Default: true.
Escape zones
On or off. Default: true.

Related: Map Type, Voice Rules, Round End Rules

Voice Rules #

Who hears whom on voice chat: everyone, only teammates, the dead only the dead and the living only the living, or only those within a distance (0: any distance, with the other rules). Spectators hear spectators. Voice Override changes it for one player; Mute Voice still mutes.

Inputs

Run Flow
Runs this node.

Outputs

Then Flow
Goes on when it's done.

Settings

Who hears
Pick one: Everyone hears everyone, Teammates only, Dead with dead, alive with alive, Teammates, and dead with dead, Only within the distance. Default: team. Choices: Everyone hears everyone, Teammates only, Dead with dead, alive with alive, Teammates, and dead with dead, Only within the distance.
Within (units, 0: any)
A number from 0 to 8192. Default: 0. From 0 up to 8192.

Related: Map Type, Remove Map Objectives, Round End Rules

Round End Rules #

Stops rounds ending by themselves: when a team is wiped out, when the time runs out, or either (End Round is then the only way a round ends). Ending as usual undoes it; a new mode starts as usual.

Inputs

Run Flow
Runs this node.

Outputs

Then Flow
Goes on when it's done.

Settings

Rounds don't end when
Pick one: (Ending as usual), A team is wiped out, Time runs out, Either (only End Round ends them). Default: elim. Choices: (Ending as usual), A team is wiped out, Time runs out, Either (only End Round ends them).

Related: Start Vote, Vote Count, Voice Rules

Start Vote #

Asks everyone (or a team, or the living) a question with 2 to 8 answers for some seconds; then runs the winning answer's output, Tie, or No votes. Bots vote at random if Bots vote is on. Only one vote at a time, and never over the server's map or mode vote (then No votes runs). Vote Count reads the result.

Inputs

Run Flow
Runs this node.

Outputs

Then Flow
Goes on when it's done.
1 Flow
Runs on 1.
2 Flow
Runs on 2.
3 Flow
Runs on 3.
4 Flow
Runs on 4.
5 Flow
Runs on 5.
6 Flow
Runs on 6.
7 Flow
Runs on 7.
8 Flow
Runs on 8.
Tie Flow
Runs on Tie.
No votes Flow
Runs when nothing was found.

Settings

Question
Text: letters, digits, spaces and plain punctuation. Default: Next round?. Up to 60.
Answers
A number from 2 to 8. Default: 2. From 2 up to 8.
Answer 1
Text: letters, digits, spaces and plain punctuation. Default: Knives. Up to 30.
Answer 2
Text: letters, digits, spaces and plain punctuation. Default: Pistols. Up to 30.
Answer 3
Text: letters, digits, spaces and plain punctuation. Default: Rifles. Up to 30.
Answer 4
Text: letters, digits, spaces and plain punctuation. Default: Snipers. Up to 30.
Answer 5
Text: letters, digits, spaces and plain punctuation. Default: Shotguns. Up to 30.
Answer 6
Text: letters, digits, spaces and plain punctuation. Default: Grenades. Up to 30.
Answer 7
Text: letters, digits, spaces and plain punctuation. Default: Random. Up to 30.
Answer 8
Text: letters, digits, spaces and plain punctuation. Default: Normal. Up to 30.
Seconds
A number from 5 to 60. Default: 15. From 5 up to 60.
Who votes
Pick one: Everyone, Terrorists, Counter-Terrorists, The living. Default: all. Choices: Everyone, Terrorists, Counter-Terrorists, The living.
Bots vote
On or off. Default: false.

Related: Vote Count, Round End Rules, Voice Rules
