    Is Holding Button

    valuein.holding
    Is Holding Button
    • Player
    • Holding

    Is the player holding this button down right now? (What reached the server: it trails their screen by their ping.)

    Inputs (1)
    Player Player
    The player. Needs a wire.
    Outputs (1)
    Holding Yes/No
    Holding: yes or no.
    Settings (1)
    Button
    Pick one: Attack (fire), Attack 2 (right click), Use (E), Jump, Duck, Reload, Walk (Shift), Forward, Back, Move left, Move right. Default: attack.
    Notes (1)

    What reached the server, so it trails the player's screen by their ping. Use it inside a flow that's already running (a timer, On Tick) to ask whether fire or duck is held right now.

    Related:Player Pressed ButtonTell Player To Bind

    Tell Player To Bind

    actionin.tell_bind
    Tell Player To Bind
    • Player (empty: everyone)

    Shows how to bind a key to a Player Command: the line to type in the console (bind f "ls_dash"). Nothing is bound for them: the game never lets a server change a player's keys.

    Inputs (2)
    Run Flow
    Runs this node.
    Player (empty: everyone) Player
    Player (empty: everyone): a player. Optional.
    Outputs (1)
    Then Flow
    Goes on when it's done.
    Settings (2)
    Key
    A name, as the map or the game knows it (letters, digits, _ . -). Default: f.
    Command (ls_...)
    A name, as the map or the game knows it (letters, digits, _ . -). Default: ls_dash.
    Related:Player CommandIs Holding Button

    Made from the app's own catalog (nodes.json, nodehelp.json, limits.ts), so it matches the app.
