Set Weather #

Rain, snow or clear weather for everyone or one player, kept through respawns (Counter-Strike 1.6 and Condition Zero draw it; how much depends on the player's settings).

Players with weather effects turned off in their options see nothing; it's only looks (no sounds, no slowdown).

Inputs

Run Flow
Runs this node.
Player (empty: everyone) Player
Player (empty: everyone): a player. Optional.

Outputs

Then Flow
Goes on when it's done.

Settings

Weather
Pick one: Clear, Rain, Snow. Default: rain. Choices: Clear, Rain, Snow.

Limits: Effect messages a frame (48 by default, hosts can raise it to 160; slow above 96).

Related: Set Fog, Set Frag Limit, Frag Limit

Set Fog #

Fog of a color and thickness for everyone or one player (0 thickness: none), kept through respawns. It depends on the player's renderer: OpenGL draws it, software mode doesn't.

OpenGL draws fog; the software renderer doesn't. Thickness 0.001 to 0.005 is a light haze; 0.02 and up hides things a short way off.

Inputs

Run Flow
Runs this node.
Player (empty: everyone) Player
Player (empty: everyone): a player. Optional.

Outputs

Then Flow
Goes on when it's done.

Settings

Red
A number from 0 to 255. Default: 128. From 0 up to 255.
Green
A number from 0 to 255. Default: 128. From 0 up to 255.
Blue
A number from 0 to 255. Default: 128. From 0 up to 255.
Thickness
A number from 0 to 0.05. Default: 0.002. From 0 up to 0.05.

Limits: Effect messages a frame (48 by default, hosts can raise it to 160; slow above 96).

Careful: Thick fog hides players from people but not from bots.

Related: Set Weather, Set Frag Limit, Frag Limit
