    Set Player Modifier

    actionup.mod
    Set Player Modifier
    • Player
    • Times

    Multiplies something about a player until they die: max health, speed, reload or swap time (0.6 = 40 % faster), damage, revive time, fire rate (1.25 = 25 % faster). Perks multiply on top.

    Inputs (3)
    Run Flow
    Runs this node.
    Player Player
    The player. Needs a wire.
    Times Number
    Times: a number. Leave it empty to use the setting.
    Outputs (1)
    Then Flow
    Goes on when it's done.
    Settings (2)
    What
    Pick one: Max health, Speed, Reload time, Weapon swap time, Damage, Revive time, Fire rate. Default: speed.
    Times
    A number from 0.1 to 10. A wire into the pin of the same name is used instead. Default: 1.2.
    Notes (1)

    Needs Loner-Strike's components plugin, which comes with the app.

    Related:Player ModifierGive PerkBuy Perk

    Drop Pickup

    actionup.pickup
    Drop Pickup
    • At
    • Pickup

    Drops a pickup at an entity; whoever walks over it takes it (Pickup Taken says what it was). A kind like resupply, doublepay, onehit, airstrike, or anything you handle yourself.

    Inputs (2)
    Run Flow
    Runs this node.
    At Entity
    At: an entity (a thing in the map). Needs a wire.
    Outputs (2)
    Then Flow
    Goes on when it's done.
    Pickup Entity
    Pickup: an entity (a thing in the map).
    Settings (3)
    Kind
    A name, as the map or the game knows it (letters, digits, _ . -). Default: resupply.
    Lasts (seconds)
    A number from 1 to 600. Default: 25.
    Color
    Pick one: White, Green, Blue, Purple, Gold, Red. Default: gold.
    Notes (1)

    Needs Loner-Strike's components plugin, which comes with the app.

            Turrets

            actionturret.setup
            Turrets

            Turrets: friendly creatures that shoot the horde. A kit (Give Turret Kit, or a shop line with give=turret) is placed with USE where the player looks; bots are offered turret spots at this price. Price 0: off.

            Inputs (1)
            Run Flow
            Runs this node.
            Outputs (1)
            Then Flow
            Goes on when it's done.
            Settings (5)
            Price
            A number from 0 to 100000. Default: 2500.
            Lasts (seconds, 0: until destroyed)
            A number from 0 to 3600. Default: 150.
            At once per player
            A number from 1 to 8. Default: 1.
            Creature type
            A name, as the map or the game knows it (letters, digits, _ . -). Default: turret.
            Bots buy them
            On or off. Default: true.
            Notes (1)

            Needs Loner-Strike's components plugin, which comes with the app.

            Related:Give Turret KitPlace TurretTurret Kits
