    Variables

    4 Game Mode Studio nodes. Pick one for its pins, settings and limits.

    valueGet VariableReads one of this mode's variables (a per-player one needs a Player, a per-team one a Team).actionSet VariableSets one of this mode's variables.actionAdd To VariableAdds to a number variable (a negative amount takes away).actionToggle VariableFlips a yes/no variable (yes becomes no, no becomes yes); New Value is what it is now.

    Inputs (3)
    Run Flow
    Runs this node.
    Player Player
    The player. Optional.
    Team Team

    Amount Number
    Amount: a number. Leave it empty to use the setting.
    Settings (2)
    Variable
    Picked from this mode's own pieces.
    Amount
    A number from -100000 to 100000. A wire into the pin of the same name is used instead. Default: 1.

    Toggle Variable

    • Team

    Inputs (2)

    Runs this node.
    Player Player
    The player. Optional.
    Team Team
    The team. Optional.
    Outputs (1)
    Then Flow
    Goes on when it's done.
    New value Yes/No
    New value: yes or no.
    Settings (1)
    Variable
    Picked from this mode's own pieces.
