    Buying

    2 Game Mode Studio nodes. Pick one for its pins, settings and limits.

    actionBuyingWhere players can buy: anywhere, only in buy zones, or nowhere.actionAllow BuyingLets players buy only some things (or everything again).

    Buying

    actionbuy.where
    Buying

    Where players can buy: anywhere, only in buy zones, or nowhere.

    Settings (1)
    Where
    Pick one: Anywhere, Only in buy zones, Nowhere (buying off). Default: anywhere.
    Related:Allow Buying

    Allow Buying

    actionbuy.allow
    Allow Buying

    Lets players buy only some things (or everything again).

    Settings (1)
    What
    Pick one: Everything, Pistols, armor and grenades, Everything but sniper rifles, Everything but the AWP, Everything but grenades, Everything but machine guns, Armor only, Nothing at all (the spawn pistol stays). Default: all.
    Related:Buying

    Made from the app's own catalog (nodes.json, nodehelp.json, limits.ts), so it matches the app.
