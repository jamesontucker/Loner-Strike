Bots

Game Mode Studio's Bots nodes (20): what each does, its inputs and outputs, settings, limits and related nodes.

Made from the app's own catalog (nodes.json, nodehelp.json, limits.ts), so it always matches the app.

Bots: Phase #

Tells the bots what part of the game it is: Loot (nobody is an enemy: they gear up and keep apart), Fight, or back to normal. Personality influence: 0 they obey exactly; 50 as usual; 100 each bot's personality and skill decide (a careful one may turn a risky job down, a slow one starts later).

Inputs

Run Flow
Runs this node.
Personality influence Number
Personality influence: a number. Leave it empty to use the setting.

Outputs

Then Flow
Goes on when it's done.

Settings

Phase
Pick one: Loot (no enemies), Fight, Normal. Default: loot. Choices: Loot (no enemies), Fight, Normal.
Personality influence (0-100)
A number from 0 to 100. A wire into the pin of the same name is used instead. Default: 50. From 0 up to 100.

Needs Loner-Strike's components plugin, which comes with the app.

Related: Bots: Don't Buy, Bots: Friends, Bots: Tag

Bots Avoid Area #

Marks a place bots keep away from: a Position with a radius, or At entity (it rides along: a carrier, a burning player, a trigger volume; it ends when that's gone). Strength 1-10: 5 and up they won't stand in it, below they only path round it. Seconds: 0 till Bots Stop Avoiding. Which bots: every bot, or one team's (the carrier's own team can be left out). The same tag again moves or changes it. The bot brain keeps 32 at once.

Inputs

Run Flow
Runs this node.
Position Vector
The position.
At entity Entity
At entity: an entity (a thing in the map). Optional.

Outputs

Then Flow
Goes on when it's done.

Settings

Tag
A name, as the map or the game knows it (letters, digits, _ . -). Default: danger.
Radius
A number from 16 to 4096. Default: 160. From 16 up to 4096.
Strength
A number from 1 to 10. Default: 6. From 1 up to 10.
Seconds (0: till stopped)
A number from 0 to 3600. Default: 0. From 0 up to 3600.
Which bots
Pick one: Every bot, Terrorist bots, Counter-Terrorist bots. Default: all. Choices: Every bot, Terrorist bots, Counter-Terrorist bots.

Limits: Areas bots avoid at once (16 by default, hosts can raise it to 32; slow above 24).

Needs Loner-Strike's components plugin, which comes with the app.

Related: Bots Stop Avoiding, Add Bots, Remove Bots

Add Bots #

Adds bots through the bot brain's own commands: how many, to which team, how good (new bots only). Never more than the free slots (one is kept open for a person). The host's bot count comes back at the next map.

Inputs

Run Flow
Runs this node.
How many Number
How many: a number. Leave it empty to use the setting.

Outputs

Then Flow
Goes on when it's done.

Settings

How many
A number from 1 to 31. A wire into the pin of the same name is used instead. Default: 2. From 1 up to 31.
Team
Pick one: Either (the game balances), Terrorists, Counter-Terrorists. Default: any. Choices: Either (the game balances), Terrorists, Counter-Terrorists.
Difficulty
Pick one: The host's setting, Easy, Normal, Hard, Expert. Default: host. Choices: The host's setting, Easy, Normal, Hard, Expert.

Related: Remove Bots, Bots Stop Avoiding, Bots Avoid Area
