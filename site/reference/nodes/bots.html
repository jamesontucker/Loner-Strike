    Bots: Phase

    actionbots.phase
    Bots: Phase
    • Personality influence

    Tells the bots what part of the game it is: Loot (nobody is an enemy: they gear up and keep apart), Fight, or back to normal. Personality influence: 0 they obey exactly; 50 as usual; 100 each bot's personality and skill decide (a careful one may turn a risky job down, a slow one starts later).

    Inputs (1)
    Run Flow
    Runs this node.
    Personality influence Number
    Personality influence: a number. Leave it empty to use the setting.
    Settings (2)
    Phase
    Pick one: Loot (no enemies), Fight, Normal. Default: loot.
    Personality influence (0-100)
    A number from 0 to 100. A wire into the pin of the same name is used instead. Default: 50.
    Notes (1)

    Needs Loner-Strike's components plugin, which comes with the app.

    actionbots.goal
    Bots: Goal
    • Bot
    • At
    • Priority
    • For (seconds)

    Gives bots something to do at an entity: defend or capture it, use it (hold USE), loot it, or go and hold there, with a priority (0-100), for some seconds, within a radius. Personality influence: 0 they obey exactly; 50 as usual; 100 each bot's personality and skill decide (a careful one may turn a risky job down, a slow one starts later).

    Inputs (5)
    Run Flow
    Runs this node.
    Bot Player
    Bot: a player. Optional.
    At Entity
    At: an entity (a thing in the map). Needs a wire.
    Priority Number
    Priority: a number. Leave it empty to use the setting.
    For (seconds) Number
    For (seconds): a number. Leave it empty to use the setting.
    Personality influence Number
    Personality influence: a number. Leave it empty to use the setting.
    Settings (7)
    Which bots
    Pick one: All bots, Counter-Terrorist bots, Terrorist bots, The wired bot, Bots with this tag. Default: all.
    Tag
    A name, as the map or the game knows it (letters, digits, _ . -).
    Goal
    Pick one: Defend it, Capture it, Use it, Loot it, Go and hold there, Hunt it (a player or creature, wherever it goes). Default: defend.
    Priority
    A number from 0 to 100. A wire into the pin of the same name is used instead. Default: 50.

    A number from 1 to 3600. A wire into the pin of the same name is used instead. Default: 60.

    Bots Avoid Area

    actionbots.avoid
    Bots Avoid Area
    • Position
    • At entity

    Marks a place bots keep away from: a Position with a radius, or At entity (it rides along: a carrier, a burning player, a trigger volume; it ends when that's gone). Strength 1-10: 5 and up they won't stand in it, below they only path round it. Seconds: 0 till Bots Stop Avoiding. Which bots: every bot, or one team's (the carrier's own team can be left out). The same tag again moves or changes it. The bot brain keeps 32 at once.

    Inputs (2)
    Run Flow
    Runs this node.
    Position Vector
    The position.
    At entity Entity
    At entity: an entity (a thing in the map). Optional.
    Settings (5)
    Tag
    A name, as the map or the game knows it (letters, digits, _ . -). Default: danger.
    Radius
    A number from 16 to 4096. Default: 160.
    Strength
    A number from 1 to 10. Default: 6.
    Seconds (0: till stopped)
    A number from 0 to 3600. Default: 0.
    Which bots
    Pick one: Every bot, Terrorist bots, Counter-Terrorist bots. Default: all.
    Limits (1)
    Areas bots avoid at once
    16 by default; hosts can raise it to 32. Above 24 the server may slow down.
    Notes (1)

    Needs Loner-Strike's components plugin, which comes with the app.

    Add Bots

    actionbotctl.add
    Add Bots
    • How many

    Adds bots through the bot brain's own commands: how many, to which team, how good (new bots only). Never more than the free slots (one is kept open for a person). The host's bot count comes back at the next map.

    Inputs (1)
    Run Flow
    Runs this node.
    How many Number
    How many: a number. Leave it empty to use the setting.
    Settings (3)
    How many
    A number from 1 to 31. A wire into the pin of the same name is used instead. Default: 2.
    Team
    Pick one: Either (the game balances), Terrorists, Counter-Terrorists. Default: any.
    Difficulty
    Pick one: The host's setting, Easy, Normal, Hard, Expert. Default: host.
