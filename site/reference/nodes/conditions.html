    Is Team

    actioncond.is_team
    Is Team
    • Player
    • Team
    • True
    • False

    Checks which team a player is on. Nobody (an empty attacker) is on no team, so that goes to False.

    Inputs (2)
    Run Flow
    Runs this node.
    Player Player
    The player. Needs a wire.
    Team Team
    The team. Leave it empty to use the setting.
    Settings (1)
    Team
    Pick one: Terrorists, Counter-Terrorists. A wire into the pin of the same name is used instead. Default: t.
