    Timers

    11 Game Mode Studio nodes. Pick one for its pins, settings and limits.

    actionDelayWaits, then carries on.flowRepeatRuns Each every few seconds, a number of times (0: until the round ends).actionCountdownCounts down on everyone's screen, then runs Done.actionStop TimersStops every Delay, Repeat and Countdown of this mode.actionStop TimerStops one Delay, Repeat or Countdown.actionRetriggerable DelayWaits, then carries on; flow coming in again while waiting starts the wait again.actionSet Timer by FunctionRuns a Function (with its own graph) after some seconds, again and again if Looping.actionSet Timer by EventRuns a Custom Event (with no inputs) after some seconds, again and again if Looping.actionTimelinePlays a Timeline (My mode, Timelines): values that change over time (a number, a position, a color) and events at set moments.actionClear TimerStops a timer (a Delay, Repeat, Countdown or Set Timer's handle).valueIs Timer ActiveIs the timer waiting to run?

    Delay

    actiontimer.delay
    Delay
    • Seconds
    • Timer

    Waits, then carries on. Paused with the world while debugging.

    Inputs (2)
    Run Flow
    Runs this node.
    Seconds Number
    Seconds: a number. Leave it empty to use the setting.
    Outputs (2)
    Then Flow
    Goes on when it's done.
    Timer Timer
    The timer.
    Settings (1)
    Seconds
    A number from 0.1 to 3600. A wire into the pin of the same name is used instead. Default: 3.
    Notes (1)

    Waits, then goes on. Other things keep running while it waits. Running it again before it's done starts another wait.

    Related:RepeatCountdownStop Timers

    Repeat

    flowtimer.repeat
    Repeat
    • Every (s)
    • Each
    • Timer

    Runs Each every few seconds, a number of times (0: until the round ends). Then runs at once.

    Inputs (2)
    Run Flow
    Runs this node.
    Every (s) Number
    Every (s): a number. Leave it empty to use the setting.
    Outputs (3)
    Then Flow
    Goes on when it's done.
    Each Flow
    Runs every time the timer fires.
    Timer Timer
    The timer.
    Settings (2)
    Every (seconds)
    A number from 0.1 to 3600. A wire into the pin of the same name is used instead. Default: 5.
    Times (0 = until the round ends)
    A number from 0 to 10000. Default: 0.
    Notes (1)

    Cost: A short interval with a lot after Tick is the most common way a mode gets heavy. Half a second or more is usually plenty.

    Related:DelayCountdownStop Timers

    Timeline

    actiontimeline.play
    Timeline
    • Play
    • Play from Start
    • Stop
    • Reverse
    • Reverse from End
    • Set New Time
    • New Time
    • Update
    • Finished
    • Forward
    • Time

    Plays a Timeline (My mode, Timelines): values that change over time (a number, a position, a color) and events at set moments. Update runs every tick while it plays; Finished at the end. In a Function with a Player input, each player has their own. Double-click to edit its tracks.

    Inputs (7)
    Play Flow
    Runs this node.
    Play from Start Flow
    Runs Play from Start.
    Stop Flow
    Runs Stop.
    Reverse Flow
    Runs Reverse.
    Reverse from End Flow
    Runs Reverse from End.
    Set New Time Flow
    Runs Set New Time.
    New Time Number
    New Time: a number.
    Outputs (4)
    Update Flow
    Runs on Update.
    Finished Flow
    Runs on Finished.
    Forward Yes/No
    Forward: yes or no.
    Time Number
    Time: a number.
    Settings (1)
    Timeline
    Picked from this mode's own pieces.
    Notes (2)

    Each key says how the track goes to the next: Linear, Constant (a step), Ease In, Ease Out, Ease In-Out, or Custom, where you drag the key's tangent handles to shape the curve (Alt drags one side; Auto tangents puts them back). The plugin works the curves out with a few multiplications a tick, no tables.

    Cost: A Timeline in a Function with a Player input runs once per player: up to 32 copies, each ticking 20 times a second at the default Tick.

    Related:Clear TimerIs Timer ActiveSet Timer by Event
