    Show Message

    actionmsg.broadcast
    Show Message
    • Player

    Shows a big message in the middle of the screen, to one player or everyone (no Player).

    Inputs (2)
    Run Flow
    Runs this node.
    Player Player
    The player. Optional.
    Outputs (1)
    Then Flow
    Goes on when it's done.
    Settings (2)
    Text
    Text: letters, digits, spaces and plain punctuation. Default: Hello!. Up to 100.
    Seconds
    A number from 1 to 20. Default: 3.
    Related:Show HUD TextChat MessageProgress Bar

    Show HUD Text

    actionmsg.hud
    Show HUD Text
    • Player
    • Value

    Shows text in a HUD slot, to one player or everyone (no Player). A Value wired in goes after the text.

    Inputs (3)
    Run Flow
    Runs this node.
    Player Player
    The player. Optional.
    Value Anything
    The value. Optional.
    Outputs (1)
    Then Flow
    Goes on when it's done.
    Settings (3)
    Text
    Text: letters, digits, spaces and plain punctuation. Default: Score:. Up to 100.
    Where
    Pick one: Top middle, Left, Right, Middle. Default: left.
    Seconds
    A number from 0.5 to 60. Default: 4.
    Notes (1)

    Shows a line of text on the player's screen (everyone's when no player is wired in) for a few seconds. Each of the four slots holds one line, so a new message in the same slot replaces the old one.

    Related:Show MessageChat MessageProgress Bar

    Status Icon

    actionmsg.status_icon
    Status Icon
    • Player
    • Color (wins over the setting)

    Shows, flashes or hides one of the game's own HUD status icons (the buy zone cart, C4, the defuser, the rescue zone...) for a player or everyone (no Player), in a color. Only the icons every player's game has (its hud.txt): for your own pictures use Objective Marker or Show HUD Text. Until death: it goes when they die or leave.

    Inputs (3)
    Run Flow
    Runs this node.
    Player Player
    The player. Optional.
    Color (wins over the setting) Color
    Color (wins over the setting): color. Optional.
    Outputs (1)
    Then Flow
    Goes on when it's done.
    Settings (6)
    Icon
    Pick one: Buy zone (cart), C4, Defuser, Rescue zone, Escape zone, VIP safety zone, Stopwatch, Skull, Small C4, Small VIP, Hostage, Dollar sign…. Default: buyzone.
    Show
    Pick one: On, Flashing, Off. Default: on.
    Red
    A number from 0 to 255. Default: 0.
    Green
    A number from 0 to 255. Default: 160.
    Blue
    A number from 0 to 255. Default: 0.
    Until death
    On or off. Default: true.
    Limits (1)
    Effect messages a frame
    48 by default; hosts can raise it to 160. Above 96 the server may slow down.
    Related:Kill Feed LineNotify AdminsChat To Team

    Kill Feed Line

    actionmsg.killfeed
    Kill Feed Line
    • Killer
    • Victim
    • Headshot

    A line in the top-right kill feed for everyone: Killer (or none: the world), the weapon's icon, Victim, and the headshot mark. Only the feed: nobody dies, nothing is counted (Player Killed doesn't run).

    Inputs (4)
    Run Flow
    Runs this node.
    Killer Player
    Killer: a player. Optional.
    Victim Player
    Victim: a player. Needs a wire.
    Headshot Yes/No
    Headshot: yes or no. Leave it empty to use the setting.
    Outputs (1)
    Then Flow
    Goes on when it's done.
    Settings (2)
    Weapon icon
    Pick one: knife, ak47, m4a1, awp, deagle, usp, glock18, p228, fiveseven, elite, scout, g3sg1…. Default: knife.
    Headshot
    On or off. A wire into the pin of the same name is used instead. Default: false.
    Limits (1)
    Effect messages a frame
    48 by default; hosts can raise it to 160. Above 96 the server may slow down.
    Related:Status IconNotify AdminsChat To Team
