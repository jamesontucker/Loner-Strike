    Squads

    4 Game Mode Studio nodes. Pick one for its pins, settings and limits.

    actionSet SquadPuts a player in a squad (1 to 32; 0 none).valueSquad OfThe squad a player is in (0 none).valueSquads LeftHow many squads still have someone alive (a living player in no squad counts as one).actionSquad Friendly FireWhether squad mates can hurt each other.

    Set Squad

    actionsquad.set
    Set Squad
    • Player
    • Squad

    Puts a player in a squad (1 to 32; 0 none). Squad mates are on one side for the bots, and can't hurt each other unless squad friendly fire is on.

    Inputs (3)
    Run Flow
    Runs this node.
    Player Player
    The player. Needs a wire.
    Squad Number
    Squad: a number. Leave it empty to use the setting.
    Outputs (1)
    Then Flow
    Goes on when it's done.
    Settings (1)
    Squad
    A number from 0 to 32. A wire into the pin of the same name is used instead. Default: 1.
    Related:Squad OfSquads LeftSquad Friendly Fire

      Squad Friendly Fire

      actionsquad.friendly_fire
      Squad Friendly Fire
      • On

      Whether squad mates can hurt each other.

      Inputs (2)
      Run Flow
      Runs this node.
      On Yes/No
      On: yes or no. Leave it empty to use the setting.
      Outputs (1)
      Then Flow
      Goes on when it's done.
      Settings (1)
      On
      On or off. A wire into the pin of the same name is used instead. Default: false.
