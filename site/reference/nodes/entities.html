      Spawn Prop

      actionent.spawn_prop
      Spawn Prop
      • At entity
      • At position
      • Local offset (forward, right, up)
      • Rotation (pitch, yaw, roll)
      • Rotation offset
      • Velocity
      • Scale
      • Model
      • Entity
      • Spawned
      • Failed
      • Success
      • Moved
      • Failure reason

      A model (models/...mdl, loaded with the map) at an entity's place; solid or not. If the spot is blocked (Unreal's Spawn Collision Handling): Always spawn, ignore collisions (Unreal's Always Spawn: it may get stuck); Try a nearby spot, but always spawn (Adjust If Possible But Always Spawn); Try a nearby spot, don't spawn if still blocked (Adjust If Possible But Don't Spawn If Colliding); Don't spawn if blocked (Do Not Spawn); or Retry every N seconds up to M tries (0: until it's clear). Nearby means within Max distance; Moved says it was moved. Outputs: Then goes on right away; Spawned once it exists, Failed once it gives up (Retry can make these come later); Entity, Success, Moved and Failure Reason (Blocked, Out of entity slots, Limit reached, Missing file, Retries used up, Bad input) let you try a fallback, like another spot. Where: At entity (its spot, moved by Local offset along its own forward, right and up; it faces the way the entity does if Face the way At entity faces is on, turned by Rotation offset) or At position. Rotation (pitch, yaw, roll) sets the facing outright; Velocity starts it moving (a still thing then falls and slides); Scale sizes models and sprites.

      Inputs (9)
      Run Flow
      Runs this node.

      At position Vector
      At position: a position or direction (X, Y, Z). Optional.
      Local offset (forward, right, up) Vector
      Local offset (forward, right, up): a position or direction (X, Y, Z). Optional.
      Rotation (pitch, yaw, roll) Vector
      Rotation (pitch, yaw, roll): a position or direction (X, Y, Z). Optional.
      Rotation offset Vector
      Rotation offset: a position or direction (X, Y, Z). Optional.
      Velocity Vector
      Velocity: a position or direction (X, Y, Z). Optional.
      Scale Number
      Scale: a number. Leave it empty to use the setting.
      Model Model
      The model. Leave it empty to use the setting.
      Outputs (7)
      Then Flow
      Goes on when it's done.
      Entity Entity
      The entity.
      Spawned Flow
      Runs on Spawned.
      Failed Flow
      Runs on Failed.
      Success Yes/No
      Success: yes or no.
      Moved Yes/No
      Moved: yes or no.
      Failure reason Spawn Failure
      Failure reason: enum:ls_spawn_fail. Values: None, Blocked, Out of entity slots, Limit reached, Missing file, Retries used up, Bad input.
      Settings (8)
      Model
      Picked from this mode's own pieces. A wire into the pin of the same name is used instead. Default: models/w_c4.mdl.
      Solid
      On or off. Default: true.
      If the spot is blocked
      Pick one: Always spawn, ignore collisions, Try a nearby spot, but always spawn, Try a nearby spot, don't spawn if still blocked, Don't spawn if blocked, Retry every N seconds up to M tries. Default: nearby.
      Max distance for a nearby spot
      A number from 16 to 1024. Default: 128.
      Retry every (seconds)
      A number from 0.1 to 60. Default: 1.
      Retry tries (0: until clear)
      A number from 0 to 1000. Default: 10.
      Face the way At entity faces
      On or off. Default: true.
      Scale
      A number from 0.05 to 10. A wire into the pin of the same name is used instead. Default: 1.
      Notes (1)

      Careful: Each prop is an entity; the game has a limit (about 900). Remove props you don't need any more.

      Get Bone Position

      valueent.bone_pos
      Get Bone Position
      • Entity
      • Position
      • Angles
      • Found

      Where a bone of a player's or any model entity's skeleton is now (like Bip01 R Hand or Bip01 Head), and which way it points. Model is only for the list of bones; the bone is looked up by name in the model the entity really has, and Found is No when it has no such bone. Positions follow the server's animation: close, not pixel-exact.

      Inputs (1)
      Entity Entity
      The entity. Needs a wire.
      Outputs (3)
      Position Vector
      The position.
      Angles Vector
      Pitch, yaw and roll of the bone.
      Found Yes/No
      No when the entity's model has no bone with that name, or it isn't a studio model.
      Settings (2)
      Model (for the list)
      A file in the game folder, like models/w_c4.mdl or ambience/thunder_clap.wav. Default: models/player.mdl.
      Bone
      Picked from this mode's own pieces. Default: Bip01 R Hand.
      Notes (1)

      The bone is found by name in the entity's own model each time (a player is models/player.mdl on the server, whatever skin they wear), so one node works for every player. The server poses the model from its own animation, which is close to what players see but not exact.

      Related:Get Attachment PositionDistanceGet Entity Property
