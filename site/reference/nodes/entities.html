Find Entities #

Every entity of a class or with a name, as an array (at most 512). Looks through the whole map: keep it in a variable instead of in a loop.

Outputs

Entities array<entity>
Entities: a list of entity (thing in the map)s.

Settings

By
Pick one: Class, Name. Default: class. Choices: Class, Name.
Class or name
A name, as the map or the game knows it (letters, digits, _ . -). Default: info_target.

Cost: Searches the whole map. Find once (at a round's start) and keep the list in a variable instead of finding again and again.

Related: Entity Name Of, Spawn Prop, Entity Class Of

Spawn Prop #

A model (models/...mdl, loaded with the map) at an entity's place; solid or not. Where: At entity (its spot, moved by Local offset along its own forward, right and up; it faces the way the entity does if Face the way At entity faces is on, turned by Rotation offset) or At position. Rotation (pitch, yaw, roll) sets the facing outright; Velocity starts it moving (a still thing then falls and slides); Scale sizes models and sprites.

Puts a model in the world at an entity's place. The model is loaded when the map loads, so it must be a file the server and players have.

Rotation offset Vector
Rotation offset: a position or direction (X, Y, Z). Optional.
Velocity Vector
Velocity: a position or direction (X, Y, Z). Optional.
Scale Number
Scale: a number. Leave it empty to use the setting.

Outputs

Then Flow
Goes on when it's done.
Prop Entity
Prop: an entity (a thing in the map).

Settings

Model
A file in the game folder, like models/w_c4.mdl or ambience/thunder_clap.wav. Default: models/w_c4.mdl.
Solid
On or off. Default: true.
Face the way At entity faces
On or off. Default: true.
Scale
A number from 0.05 to 10. A wire into the pin of the same name is used instead. Default: 1. From 0.05 up to 10.

Careful: Each prop is an entity; the game has a limit (about 900). Remove props you don't need any more.

Get Bone Position #

Where a bone of a player's or any model entity's skeleton is now (like Bip01 R Hand or Bip01 Head), and which way it points. Model is only for the list of bones; the bone is looked up by name in the model the entity really has, and Found is No when it has no such bone. Positions follow the server's animation: close, not pixel-exact.

The bone is found by name in the entity's own model each time (a player is models/player.mdl on the server, whatever skin they wear), so one node works for every player. The server poses the model from its own animation, which is close to what players see but not exact.

Inputs

Entity Entity
The entity. Needs a wire.

Outputs

Position Vector
The position.
Angles Vector
Pitch, yaw and roll of the bone.
Found Yes/No
No when the entity's model has no bone with that name, or it isn't a studio model.

Settings

Model (for the list)
A file in the game folder, like models/w_c4.mdl or ambience/thunder_clap.wav. Default: models/player.mdl.
Bone
Picked from this mode's own pieces. Default: Bip01 R Hand.

Related: Get Attachment Position, Distance, Get Entity Property

Get Attachment Position #

Where an attachment point of an entity's model is now (a gun's muzzle, a hand; models number them 0 to 3), and its angles. Model is only for the list; Found is No when the entity's real model has no such attachment. Positions follow the server's animation: close, not pixel-exact.

Attachments are a model's fixed points (a weapon's muzzle and shell ejection, a hand): most have no names, so the list shows each one's number and the bone it sits on.

Play Animation #

Plays an animation (a sequence of its model, by name or number) on a prop, an NPC or any model entity, at a speed (1 normal), from the start or not; Loop plays a one-time animation again every Length seconds (looping ones loop by themselves). Players, creatures and NPCs that are walking are animated by the game and will switch back.

Inputs

Runs this node.

Outputs

Speed

From the start

Spawn Entity #

Only classes that are safe to make while the game runs are listed: effects, sounds, markers, relays, pickups. Never players, worldspawn, game_* server controls or anything that runs commands. Files its keys name are loaded with the map; if one isn't on the server it's skipped, never a crash. Where: At entity (its spot, moved by Local offset along its own forward, right and up; it faces the way the entity does if Face the way At entity faces is on, turned by Rotation offset) or At position. Rotation (pitch, yaw, roll) sets the facing outright; Velocity starts it moving (a still thing then falls and slides); Scale sizes models and sprites.
