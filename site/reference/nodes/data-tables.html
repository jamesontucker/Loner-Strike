    Get Row

    valuetable.get_row
    Get Row
    • Key
    • Found
    • Row

    Finds the row whose key is this (the table's key column) and gives each of its cells. Found is No when no row has that key (the cells are then 0, No or empty).

    Inputs (1)
    Key Anything
    The value to look for in the key column.
    Outputs (2)
    Found Yes/No
    Yes when a row has that key.
    Row Number
    The row's number (from 0), or -1 when none has the key.
    Settings (1)
    Table
    Picked from this mode's own pieces.
    Notes (1)

    Data tables (My mode > Data tables) are grids of values you type or paste from a spreadsheet: a gun list, prices, waves. Get Row finds the row whose key column has this value and gives every cell of it as a pin.

    Get Cell

    valuetable.get_cell
    Get Cell
    • Row
    • Value

    One cell: a column of a row (rows count from 0). Past the end: 0, No or empty.

    Inputs (1)
    Row Number
    Row: a number. Leave it empty to use the setting.
    Outputs (1)
    Value Anything
    The value.
    Settings (3)
    Table
    Picked from this mode's own pieces.
    Column
    Picked from this mode's own pieces.
    Row
    A number from 0 to 255. A wire into the pin of the same name is used instead. Default: 0.

    For Each Row

    flowtable.for_each
    For Each Row
    • Each
    • Row
    • Key
    • Then

    Runs Each once for every row of the table, in order, with that row's cells; then Then.

    Inputs (1)
    Run Flow
    Runs this node.
    Outputs (4)
    Each Flow
    Runs once for every item.
    Row Number
    Row: a number.
    Key Anything
    Key: any value.
    Then Flow
    Goes on when it's done.
    Settings (1)
    Table
    Picked from this mode's own pieces.
    Notes (1)

    Cost: A table has at most 256 rows, and reading one costs almost nothing: the plugin holds tables as fixed lists.

    Related:Get CellFind RowsGet Row

    Find Rows

    valuetable.find
    Find Rows
    • Value
    • Rows

    The rows (as row numbers) where a column has this value, in order. Use Get Cell on each.

    Inputs (1)
    Value Anything
    The value. Needs a wire.
    Outputs (1)
    Rows Anything
    Rows: any value.
    Settings (2)
    Table
    Picked from this mode's own pieces.
    Column
    Picked from this mode's own pieces.
    Notes (1)

    Every row (as row numbers, in order) where the column you pick has this value. Read their cells with Get Cell, or loop over them with For Each.
