Data tables

Game Mode Studio's Data tables nodes (6): what each does, its inputs and outputs, settings, limits and related nodes.

Made from the app's own catalog (nodes.json, nodehelp.json, limits.ts), so it always matches the app.

Get Row #

Finds the row whose key is this (the table's key column) and gives each of its cells. Found is No when no row has that key (the cells are then 0, No or empty).

Data tables (My mode > Data tables) are grids of values you type or paste from a spreadsheet: a gun list, prices, waves. Get Row finds the row whose key column has this value and gives every cell of it as a pin.

Inputs

Key Anything
The value to look for in the key column.

Outputs

Found Yes/No
Yes when a row has that key.
Row Number
The row's number (from 0), or -1 when none has the key.

Settings

Table
Picked from this mode's own pieces.

Related: Get Cell, For Each Row, Find Rows

Get Cell #

One cell: a column of a row (rows count from 0). Past the end: 0, No or empty.

Reads one cell. Rows count from 0, so the first row is 0; a row past the end gives 0, No or empty text.

Inputs

Row Number
Row: a number. Leave it empty to use the setting.

Outputs

Value Anything
The value.

Settings

Table
Picked from this mode's own pieces.
Column
Picked from this mode's own pieces.
Row
A number from 0 to 255. A wire into the pin of the same name is used instead. Default: 0. From 0 up to 255.

Related: Get Row, Row Count, For Each Row

For Each Row #

Runs Each once for every row of the table, in order, with that row's cells; then Then.

Runs Each for every row in order, with that row's cells as pins (and Row, its number). Then runs once after the last.

Inputs

Run Flow
Runs this node.

Outputs

Each Flow
Runs once for every item.
Row Number
Row: a number.
Key Anything
Key: any value.
Then Flow
Goes on when it's done.

Settings

Table
Picked from this mode's own pieces.

Cost: A table has at most 256 rows, and reading one costs almost nothing: the plugin holds tables as fixed lists.

Related: Get Cell, Find Rows, Get Row

Find Rows #

The rows (as row numbers) where a column has this value, in order. Use Get Cell on each.

Every row (as row numbers, in order) where the column you pick has this value. Read their cells with Get Cell, or loop over them with For Each.

Inputs

Value Anything
The value. Needs a wire.

Outputs

Rows Anything
Rows: any value.

Settings

Table
Picked from this mode's own pieces.
Column
Picked from this mode's own pieces.

Related: Get Cell, For Each, For Each Row

Row Count #

How many rows the table has.

Outputs

Rows Number
Rows: a number.

Settings

Table
Picked from this mode's own pieces.

Related: Find Rows, Row Keys, For Each Row

Row Keys #

The table's keys (its key column), in row order.

Outputs

Keys Anything
Keys: any value.

Settings

Table
Picked from this mode's own pieces.

Related: Row Count, Find Rows, For Each Row
