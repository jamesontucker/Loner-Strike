    Cooldowns

    4 Game Mode Studio nodes. Pick one for its pins, settings and limits.

    actionStart CooldownStarts a cooldown by name (like dash) for Seconds: for each player, each team or everyone.valueIs ReadyIs this ability's cooldown over (or never started)?valueCooldown Time LeftSeconds until this ability's cooldown is over (0 when ready).actionReset CooldownEnds a cooldown now (the ability is ready again).

    Start Cooldown

    actioncd.start
    Start Cooldown
    • Player
    • Team
    • Seconds

    Starts a cooldown by name (like dash) for Seconds: for each player, each team or everyone. Is Ready says no until it's over.

    Inputs (4)
    Run Flow
    Runs this node.
    Player Player
    Whose cooldown (For: each player).
    Team Team
    Which team's cooldown (For: each team).
    Seconds Number
    How long until it's ready again.
    Outputs (1)
    Then Flow
    Goes on when it's done.
    Settings (3)
    Ability
    A name, as the map or the game knows it (letters, digits, _ . -). Default: dash.
    For
    Pick one: Each player, Each team, Everyone (one for all). Default: player.
    Seconds
    A number from 0 to 86400. A wire into the pin of the same name is used instead. Default: 5.
    Notes (1)

    One cooldown per ability name: for each player, each team, or one for everyone. Start it when the ability is used, check Is Ready before letting it run again. A player's cooldowns start clean when they leave; a new map starts them all clean.
