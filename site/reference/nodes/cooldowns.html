Cooldowns

Game Mode Studio's Cooldowns nodes (4): what each does, its inputs and outputs, settings, limits and related nodes.

Made from the app's own catalog (nodes.json, nodehelp.json, limits.ts), so it always matches the app.

Start Cooldown #

Starts a cooldown by name (like dash) for Seconds: for each player, each team or everyone. Is Ready says no until it's over.

One cooldown per ability name: for each player, each team, or one for everyone. Start it when the ability is used, check Is Ready before letting it run again. A player's cooldowns start clean when they leave; a new map starts them all clean.

Inputs

Run Flow
Runs this node.
Player Player
Whose cooldown (For: each player).
Team Team
Which team's cooldown (For: each team).
Seconds Number
How long until it's ready again.

Outputs

Then Flow
Goes on when it's done.

Settings

Ability
A name, as the map or the game knows it (letters, digits, _ . -). Default: dash.
For
Pick one: Each player, Each team, Everyone (one for all). Default: player. Choices: Each player, Each team, Everyone (one for all).
Seconds
A number from 0 to 86400. A wire into the pin of the same name is used instead. Default: 5. From 0 up to 86400.

Related: Is Ready, Cooldown Time Left, Reset Cooldown, Player Pressed Button

Is Ready #

Is this ability's cooldown over (or never started)?

Inputs

Player Player
The player. Optional.
Team Team
The team. Optional.

Outputs

Ready Yes/No
Ready: yes or no.

Settings

Ability
A name, as the map or the game knows it (letters, digits, _ . -). Default: dash.
For
Pick one: Each player, Each team, Everyone (one for all). Default: player. Choices: Each player, Each team, Everyone (one for all).

Related: Start Cooldown, Cooldown Time Left, Reset Cooldown

Cooldown Time Left #

Seconds until this ability's cooldown is over (0 when ready).

Good for a HUD line (Dash ready in 3 s).

Inputs

Player Player
The player. Optional.
Team Team
The team. Optional.

Outputs

Seconds: a number.

Settings

Ability
A name, as the map or the game knows it (letters, digits, _ . -). Default: dash.
For
Pick one: Each player, Each team, Everyone (one for all). Default: player. Choices: Each player, Each team, Everyone (one for all).

Related: Start Cooldown, Is Ready, Reset Cooldown
