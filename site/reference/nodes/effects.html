    Explosion

    actionfx.explosion
    Explosion
    • Position
    • Damage

    An explosion at a position: the look and sound, and damage to players within the radius (0: none).

    Inputs (3)
    Run Flow
    Runs this node.
    Position Vector
    The position. Needs a wire.
    Damage Number
    How much it hurts players near it (0: only the look and sound).
    Outputs (1)
    Then Flow
    Goes on when it's done.
    Settings (2)
    Damage
    A number from 0 to 500. A wire into the pin of the same name is used instead. Default: 0.
    Radius
    A number from 16 to 2000. Default: 250.
    Notes (1)

    Careful: With damage, it can kill players, and those count as deaths by the world.

    Related:Beam

    Beam

    actionfx.beam
    Beam
    • From
    • To
    • Color (wins over the setting)

    A beam of light from one position to another for some seconds.

    Inputs (4)
    Run Flow
    Runs this node.
    From Vector
    From: a position or direction (X, Y, Z). Needs a wire.
    To Vector
    To: a position or direction (X, Y, Z). Needs a wire.
    Color (wins over the setting) Color
    A color to use instead of the Color choice: wire a Color node (pick it with its picker), Make Color or a Color variable. Not wired: the Color choice.
    Outputs (1)
    Then Flow
    Goes on when it's done.
    Settings (2)
    Color
    Pick one: Red, Green, Blue, White, Gold. Default: red.
    Seconds
    A number from 0.1 to 25. Default: 1.
    Related:Explosion

    Set Light Style

    actionfx.lights
    Set Light Style

    How bright the whole map is: normal, dark, darkest, bright, or flickering.

    Inputs (1)
    Run Flow
    Runs this node.
    Outputs (1)
    Then Flow
    Goes on when it's done.
    Settings (1)
    Light
    Pick one: Normal, Dark, Darkest, Bright, Flickering. Default: normal.
    Notes (1)

    Changes the light of the whole map for everyone, until set back to Normal or the map changes.

    Related:Objective Marker

    Objective Marker

    actionfx.marker
    Objective Marker
    • Follow
    • Position
    • Player (for one player)
    • Color (wins over the setting)
    • Sprite
    • MarkerM

    A sprite that floats over an entity (wired into Follow: a player, an NPC, an interactable, a component; it follows it) or at a position, for everyone, one team or one player. The sprite is one of the game's (sprites/arrow1.spr) or your own (sprites/...spr: it goes with the mode, like its other files). Remove it with Remove Marker; it goes by itself when what it follows is gone.

    Inputs (6)
    Run Flow
    Runs this node.
    Follow Entity
    Follow: an entity (a thing in the map).
    Position Vector
    The position. Optional.
    Player (for one player) Player
    Player (for one player): a player. Optional.
    Color (wins over the setting) Color
    A color to use instead of the Red, Green and Blue settings: wire a Color node (pick it with its picker), Make Color or a Color variable. Not wired: the Red, Green and Blue settings.
    Sprite Sprite
    The sprite. Leave it empty to use the setting.
    Outputs (2)
    Then Flow
    Goes on when it's done.
    MarkerM Objective Marker
    Marker: an objective marker (an Objective Marker handle).
    Settings (8)
    Sprite
    Picked from this mode's own pieces. A wire into the pin of the same name is used instead. Default: sprites/arrow1.spr.
    Seen by
    Pick one: Everyone, Terrorists, Counter-Terrorists, The wired player. Default: all.
    Height above
    A number from 0 to 512. Default: 48.
    Size
    A number from 0.05 to 5. Default: 0.5.
    Red
    A number from 0 to 255. Default: 255.
    Green
    A number from 0 to 255. Default: 200.
    Blue
    A number from 0 to 255. Default: 0.
    Pulse
    On or off. Default: true.
    Limits (2)
    Objective markers at once
    32 by default; hosts can raise it to 256. Above 64 the server may slow down.
    Visible things at once
    128 by default; hosts can raise it to 1000. Above 200 the server may slow down.
    Related:Remove MarkerSet Light Style

    Beam Between Entities

    actionfx.beam_ents
    Beam Between Entities
    • From
    • To

    A beam from one player or entity to another that follows both as they move, for some seconds. Effects are skipped (and the debugger says so) past 24 in one server frame, so many at once can't flood players' games.

    Inputs (3)
    Run Flow
    Runs this node.
    From Entity
    From: an entity (a thing in the map). Needs a wire.
    To Entity
    To: an entity (a thing in the map). Needs a wire.
    Outputs (1)
    Then Flow
    Goes on when it's done.
    Settings (4)
    Color
    Pick one: Red, Green, Blue, White, Gold. Default: red.
    Seconds
    A number from 0.1 to 25. Default: 2.
    Width
    A number from 1 to 100. Default: 10.
    Wobble
    A number from 0 to 100. Default: 0.
    Limits (1)
    Effect messages a frame
    48 by default; hosts can raise it to 64. Above 56 the server may slow down.
    Notes (1)

    Careful: Each beam is a temporary effect in every player's game, which has a shared limit; past 24 effects in one server frame the rest are skipped.

    Related:Icon Over PlayerSprite AtTracer
