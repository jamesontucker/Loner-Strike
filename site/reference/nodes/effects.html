Effects

Game Mode Studio's Effects nodes (20): what each does, its inputs and outputs, settings, limits and related nodes.

Made from the app's own catalog (nodes.json, nodehelp.json, limits.ts), so it always matches the app.

Explosion #

An explosion at a position: the look and sound, and damage to players within the radius (0: none).

Inputs

Run Flow
Runs this node.
Position Vector
The position. Needs a wire.
Damage Number
How much it hurts players near it (0: only the look and sound).

Outputs

Then Flow
Goes on when it's done.

Settings

Damage
A number from 0 to 500. A wire into the pin of the same name is used instead. Default: 0. From 0 up to 500.
Radius
A number from 16 to 2000. Default: 250. From 16 up to 2000.

Careful: With damage, it can kill players, and those count as deaths by the world.

Related: Beam

Objective Marker #

A sprite that floats over an entity (wired into Follow: a player, an NPC, an interactable, a component; it follows it) or at a position, for everyone, one team or one player. The sprite is one of the game's (sprites/arrow1.spr) or your own (sprites/...spr: it goes with the mode, like its other files). Remove it with Remove Marker; it goes by itself when what it follows is gone.

Inputs

Run Flow
Runs this node.
Follow Entity
Follow: an entity (a thing in the map).
Position Vector
The position. Optional.
Player (for one player) Player
Player (for one player): a player. Optional.

Outputs

Then Flow
Goes on when it's done.
Marker Entity
Marker: an entity (a thing in the map).

Settings

Sprite
A file in the game folder, like models/w_c4.mdl or ambience/thunder_clap.wav. Default: sprites/arrow1.spr.
Seen by
Pick one: Everyone, Terrorists, Counter-Terrorists, The wired player. Default: all. Choices: Everyone, Terrorists, Counter-Terrorists, The wired player.
Height above
A number from 0 to 512. Default: 48. From 0 up to 512.
Size
A number from 0.05 to 5. Default: 0.5. From 0.05 up to 5.
Red
A number from 0 to 255. Default: 255. From 0 up to 255.
Green
A number from 0 to 255. Default: 200. From 0 up to 255.
Blue
A number from 0 to 255. Default: 0. From 0 up to 255.
Pulse
On or off. Default: true.

Limits: Objective markers at once (32 by default, hosts can raise it to 256; slow above 64).

Related: Remove Marker, Set Light Style

Loop Sound #

A sound that keeps playing at a spot, or riding on an entity, until Stop Sound gets its Handle (or the round ends with the entity). A .wav with loop points loops by itself; for one without, set Play again every (seconds). How many play at once is a mode setting (Limits: Loop sounds at once, 16 to start). Map sounds are best mono: a stereo .wav is heard in the middle of your head, not from where it plays. Your own sounds (sound/custom/...wav) are loaded with the map and go with the mode when you publish it.

Inputs

Run Flow
Runs this node.
On entity Entity
On entity: an entity (a thing in the map). Optional.
At position Vector
At position: a position or direction (X, Y, Z). Optional.
Volume Number
Volume: a number. Leave it empty to use the setting.
Pitch Number
Pitch: a number. Leave it empty to use the setting.
Play again every (seconds) Number
Play again every (seconds): a number. Leave it empty to use the setting.

Outputs

Then Flow
Goes on when it's done.
Handle Entity
Handle: an entity (a thing in the map).

Settings

Sound
A file in the game folder, like models/w_c4.mdl or ambience/thunder_clap.wav. Default: ambience/wind1.wav.
Volume
A number from 0 to 1. A wire into the pin of the same name is used instead. Default: 1. From 0 up to 1.
Pitch
A number from 50 to 255. A wire into the pin of the same name is used instead. Default: 100. From 50 up to 255.
Heard
Pick one: Everywhere, Far (large), Normal, Close by (small). Default: normal. Choices: Everywhere, Far (large), Normal, Close by (small).
Play again every (seconds; 0: it loops by itself)
A number from 0 to 600. A wire into the pin of the same name is used instead. Default: 0. From 0 up to 600.

Limits: Loop sounds at once (16 by default, hosts can raise it to 256; slow above 64).

Related: Play Sound on Entity, Stop Sound, Play Sound at Location

Beam Between Entities #

A beam from one player or entity to another that follows both as they move, for some seconds. Effects are skipped (and the debugger says so) past 24 in one server frame, so many at once can't flood players' games.

Inputs

Run Flow
Runs this node.
From Entity
From: an entity (a thing in the map). Needs a wire.
To Entity
To: an entity (a thing in the map). Needs a wire.

Outputs

Then Flow
Goes on when it's done.

Settings

Color
Pick one: Red, Green, Blue, White, Gold. Default: red. Choices: Red, Green, Blue, White, Gold.
Seconds
A number from 0.1 to 25. Default: 2. From 0.1 up to 25.
Width
A number from 1 to 100. Default: 10. From 1 up to 100.
Wobble
A number from 0 to 100. Default: 0. From 0 up to 100.

Limits: Effect messages a frame (48 by default, hosts can raise it to 160; slow above 96).

Related: Icon Over Player, Sprite At, Stop Sound

Icon Over Player #

A sprite floating over a player's head (the game's own, like sprites/iplayervip.spr, or your own), for some seconds or until removed (0), seen by everyone, a team or only Viewer. Remove takes the icons off that player.

The icon follows the player's head on everyone's screen who sees it. Seen by a team means the team at the moment it's shown. A sprite file that isn't on the server is left out (nothing shows).

Inputs

Run Flow
Runs this node.
Player Player
The player. Needs a wire.
Viewer Player
Viewer: a player. Optional.

Outputs

Then Flow
Goes on when it's done.

Settings

Do
Pick one: Show, Remove. Default: show. Choices: Show, Remove.
Sprite
A file in the game folder, like models/w_c4.mdl or ambience/thunder_clap.wav. Default: sprites/iplayervip.spr.
Seconds (0: until removed)
A number from 0 to 600. Default: 0. From 0 up to 600.
Height above
A number from 0 to 200. Default: 45. From 0 up to 200.
Seen by
Pick one: Everyone, Terrorists, Counter-Terrorists, Only Viewer. Default: all. Choices: Everyone, Terrorists, Counter-Terrorists, Only Viewer.

Limits: Effect messages a frame (48 by default, hosts can raise it to 160; slow above 96).

Related: Scoreboard Tag, Objective Marker, Beam Between Entities
