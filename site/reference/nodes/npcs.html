Say and Choose #

The NPC (or a narrator, with none wired) says a line and the player picks a reply; each reply runs its output (later, when they pick), and Picked says which (1-6; 0 for none). Timed out: no pick in time. Walked away: they went off, died, left or closed it. Every text can be wired (a variable, a table cell), so one node can run a whole conversation from a data table; Replies sets how many are offered (empty ones are left out). One conversation per player: a new one ends the old (as Walked away).

Spawn NPC #

Makes an NPC at an entity (wired into At), a point, or the entity with this name. Its model is loaded with the map (models/...mdl). Where: At entity (its spot, moved by Local offset along its own forward, right and up; it faces the way the entity does if Face the way At entity faces is on, turned by Rotation offset) or At position. Rotation (pitch, yaw, roll) sets the facing outright; Velocity starts it moving (a still thing then falls and slides); Scale sizes models and sprites.

NPC Move To #

Sends an NPC walking (or running) to an entity or a point now, along the map's bot navigation (straight when the map has none), facing where it goes. Arrived runs when it gets there, Failed when it can't (no way, stuck, or too long). Then it goes back to what it did, or stays there.

Inputs

Run Flow
Runs this node.
NPC Entity
NPC: an entity (a thing in the map). Needs a wire.
To entity Entity
To entity: an entity (a thing in the map). Optional.
Or point Vector
Or point: a position or direction (X, Y, Z).

Outputs

Then Flow
Goes on when it's done.
Arrived Flow
Runs on Arrived.
Failed Flow
Runs on Failed.

Settings

Speed
Pick one: Walk, Run. Default: walk. Choices: Walk, Run.
Stay there after
On or off. Default: false.

Limits: NPC moves at once (32 by default, hosts can raise it to 64; slow above 48).

Needs Loner-Strike's components plugin, which comes with the app.

Related: NPC Follow Path, NPC Stop, Hostage Follow

NPC Follow Path #

Sends an NPC along points in order: an array of positions, or a map's path_track chain by its first name. At point runs at each one, Finished at the end (never with Loop), Failed when it can't get on. Then it goes back to what it did, or stays there.

Runs this node.

NPC: an entity (a thing in the map). Needs a wire.

Outputs

Then Flow
Goes on when it's done.
At point Flow
Runs on At point.
Finished Flow
Runs on Finished.
Failed Flow
Runs on Failed.

Settings

Or path_track (first name)
A name, as the map or the game knows it (letters, digits, _ . -). Default: path1.
Speed
Pick one: Walk, Run. Default: walk. Choices: Walk, Run.
Loop
On or off. Default: false.
Stay at the end
On or off. Default: false.

Limits: NPC moves at once (32 by default, hosts can raise it to 64; slow above 48).

Needs Loner-Strike's components plugin, which comes with the app.
