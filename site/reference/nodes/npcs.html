        Say and Choose

        actionnpc.choose
        Say and Choose
        • Player
        • NPC

        • Timed out

        The NPC (or a narrator, with none wired) says a line and the player picks a reply; each reply runs its output (later, when they pick), and Picked says which (1-6; 0 for none). Timed out: no pick in time. Walked away: they went off, died, left or closed it. Every text can be wired (a variable, a table cell), so one node can run a whole conversation from a data table; Replies sets how many are offered (empty ones are left out). One conversation per player: a new one ends the old (as Walked away).

        Spawn NPC

        actionnpc.spawn
        Spawn NPC
        • At entity
        • At position
        • Local offset (forward, right, up)
        • Rotation (pitch, yaw, roll)
        • Rotation offset
        • Velocity
        • Scale
        • NPC

        Makes an NPC at an entity (wired into At), a point, or the entity with this name. Its model is loaded with the map (models/...mdl). Where: At entity (its spot, moved by Local offset along its own forward, right and up; it faces the way the entity does if Face the way At entity faces is on, turned by Rotation offset) or At position. Rotation (pitch, yaw, roll) sets the facing outright; Velocity starts it moving (a still thing then falls and slides); Scale sizes models and sprites.

        Inputs (7)
        Run Flow
        Runs this node.
        At entity Entity
        At entity: an entity (a thing in the map). Optional.
        At position Vector
        At position: a position or direction (X, Y, Z). Optional.
        Local offset (forward, right, up) Vector
        Local offset (forward, right, up): a position or direction (X, Y, Z). Optional.
        Rotation (pitch, yaw, roll) Vector
        Rotation (pitch, yaw, roll): a position or direction (X, Y, Z). Optional.
        Rotation offset Vector
        Rotation offset: a position or direction (X, Y, Z). Optional.
        Velocity Vector
        Velocity: a position or direction (X, Y, Z). Optional.
        Scale Number
        Scale: a number. Leave it empty to use the setting.
        Outputs (1)
        Then Flow
        Goes on when it's done.
        NPC Entity
        NPC: an entity (a thing in the map).
        Settings (8)
        Or the entity named
        A name, as the map or the game knows it (letters, digits, _ . -).
        Model
        A file in the game folder, like models/w_c4.mdl or ambience/thunder_clap.wav. Default: models/barney.mdl.
        Name
        Text: letters, digits, spaces and plain punctuation. Default: Guide. Up to 31.
        Facing (degrees)
        A number from -360 to 360. Default: 0.
        Behavior
        Pick one: Stand, Wander. Default: stand.
        Unkillable
        On or off. Default: true.
        Face the way At entity faces
        On or off. Default: true.
        Scale
        A number from 0.05 to 10. A wire into the pin of the same name is used instead. Default: 1.
        Notes (1)

        Needs Loner-Strike's components plugin, which comes with the app.

        NPC Move To

        actionnpc.move_to
        NPC Move To
        • NPC
        • To entity
        • Or point
        • Arrived
        • Failed

        Sends an NPC walking (or running) to an entity or a point now, along the map's bot navigation (straight when the map has none), facing where it goes. Arrived runs when it gets there, Failed when it can't (no way, stuck, or too long). Then it goes back to what it did, or stays there.

        Inputs (3)
        Run Flow
        Runs this node.
        NPC Entity
        NPC: an entity (a thing in the map). Needs a wire.
        To entity Entity
        To entity: an entity (a thing in the map). Optional.
        Or point Vector
        Or point: a position or direction (X, Y, Z).
        Settings (2)
        Speed
        Pick one: Walk, Run. Default: walk.
        Stay there after
        On or off. Default: false.
        Limits (1)
        NPC moves at once
        32 by default; hosts can raise it to 64. Above 48 the server may slow down.
        Notes (1)

        Needs Loner-Strike's components plugin, which comes with the app.

        Related:NPC Follow PathNPC StopHostage Follow

        NPC Follow Path

        actionnpc.follow_path
        NPC Follow Path
        • NPC
        • Points
        • At point
        • Finished
        • Failed

        Sends an NPC along points in order: an array of positions, or a map's path_track chain by its first name. At point runs at each one, Finished at the end (never with Loop), Failed when it can't get on. Then it goes back to what it did, or stays there.

        Inputs (2)
        Run Flow
        Runs this node.
        NPC Entity
        NPC: an entity (a thing in the map). Needs a wire.
        Points array<vector>
        Points: a list of position or direction (X, Y, Z)s. Optional.
        Settings (4)
        Or path_track (first name)
        A name, as the map or the game knows it (letters, digits, _ . -). Default: path1.
        Speed
        Pick one: Walk, Run. Default: walk.
        Loop
        On or off. Default: false.
        Stay at the end
        On or off. Default: false.
        Limits (1)
        NPC moves at once
        32 by default; hosts can raise it to 64. Above 48 the server may slow down.
        Notes (1)

        Needs Loner-Strike's components plugin, which comes with the app.
