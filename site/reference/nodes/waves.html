    Round Table On

    actionwave.table
    Round Table On

    Each Start Wave from now on plans a zombie-survival round on the map's wave spawners: how many (by round and team size), which creature types (unlocked by round, with stand-ins), their health, bosses, packs, heavies, tiers, how many alive at once. A waves.ini section replaces the built-in mix.

    Inputs (1)
    Run Flow
    Runs this node.
    Outputs (1)
    Then Flow
    Goes on when it's done.
    Settings (3)
    waves.ini section (empty: built in)
    A name, as the map or the game knows it (letters, digits, _ . -).
    Defenders
    Pick one: Counter-Terrorists, Terrorists. Default: 2.
    Creatures (no: dead players come back as the enemies)
    On or off. Default: true.
    Notes (1)

    Needs Loner-Strike's components plugin, which comes with the app.
