    For Each

    flowflow.for_each_array
    For Each
    • Break
    • Array
    • Loop Body
    • Item
    • Index#
    • Completed

    Runs Loop Body once for each item of an array (Break stops early), then Completed.

    Inputs (3)
    Run Flow
    Runs this node.
    Break Flow
    Stops the loop.
    Array Array of the node's type
    Array: a list of the type set in Holds. Needs a wire.
    Outputs (4)
    Loop Body Flow
    Runs once for every step.
    Item The node's type
    Item: the type set in Holds.
    Index# Number
    Index: a number.
    Completed Flow
    Goes on when it's done.
    Settings (1)
    Holds
    What kind of values it holds. Default: number.
    Limits (2)
    Loop steps a frame
    20000 by default; hosts can raise it to 2000000. Above 200000 the server may slow down.
    Loop steps in a Function
    1000000 by default; hosts can raise it to 10000000. Above 2000000 the server may slow down.
    Related:Make ArrayPlayers ArrayAdd
