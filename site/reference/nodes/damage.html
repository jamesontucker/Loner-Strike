    Block Damage

    The damage doesn't happen. Only in a Player About To Be Hurt flow.

    Scale Damage

    actiondmg.scale
    Scale Damage
    • Times

    Multiplies the damage (0.5 halves it). Only in a Player About To Be Hurt flow.

    Inputs (1)
    Run Flow
    Runs this node.
    Times Number
    Times: a number. Leave it empty to use the setting.
    Settings (1)
    Times
    A number from 0 to 100. A wire into the pin of the same name is used instead. Default: 0.5.

    Inputs (1)

    Settings (1)

    Deal Damage

    actiondamage.deal
    Deal Damage
    • Target
    • Attacker
    • Amount

    Hurts a player or any entity that can be hurt (a breakable, an NPC, a creature) by Amount, as if Attacker did it: kills, the kill feed, scores and Player Hurt / Player Killed count as usual. No Attacker: the world did it. Kind is what it counts as (a burn, a fall...); Hit zone is where (a head hit shows as a headshot in the kill feed; the amount isn't multiplied). Armor takes its share unless Ignore armor.

    Inputs (3)
    Run Flow
    Runs this node.
    Target Entity
    Target: an entity (a thing in the map). Needs a wire.
    Attacker Player
    Attacker: a player. Optional.
    Amount Number
    Amount: a number. Leave it empty to use the setting.
    Settings (4)
    Amount
    A number from 0 to 10000. A wire into the pin of the same name is used instead. Default: 25.
    Kind
    Pick one: Generic, Bullet, Slash (knife), Burn, Blast, Fall, Shock, Crush, Poison, Freeze. Default: generic.
    Hit zone
    Pick one: Anywhere (generic), Head, Chest, Stomach, Left arm, Right arm, Left leg, Right leg. Default: generic.
    Ignore armor
    On or off. Default: false.
    Related:Set DamageScale DamageBlock Damage
