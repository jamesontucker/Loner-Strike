Give Weapon #

Gives a living player a weapon and spare bullets. Does nothing for a dead player, or one who already has that weapon (the debugger marks that). A weapon's name can be wired in (from a data table, say): ak47, deagle, knife...

Gives the weapon with reserve ammo. A player who already has one in that slot gets it as well; Strip first for a clean loadout.

Inputs

Run Flow
Runs this node.
Player Player
The player. Needs a wire.
Weapon Text
Weapon: text. Leave it empty to use the setting.
Spare bullets Number
Spare bullets: a number. Leave it empty to use the setting.

Outputs

Then Flow
Goes on when it's done.

Settings

Weapon
Pick one: AK-47, M4A1, AWP, Scout, FAMAS, Galil, AUG, SG 552, MP5, P90, UMP 45, MAC-10…. A wire into the pin of the same name is used instead. Default: ak47. Choices: AK-47, M4A1, AWP, Scout, FAMAS, Galil, AUG, SG 552, MP5, P90, UMP 45, MAC-10, TMP, M3 shotgun, XM1014 shotgun, M249, Desert Eagle, USP, Glock, P228, Five-SeveN, Dual Elites, HE grenade, Flashbang, Smoke grenade.
Spare bullets
A number from 0 to 250. A wire into the pin of the same name is used instead. Default: 90. From 0 up to 250.

Related: Strip Weapons, Set Health, Set Armor
