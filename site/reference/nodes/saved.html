      Top Players

      flowsave.top
      Top Players
      • Each
      • Rank
      • Name
      • Value
      • Then

      The best players by a saved value (Saved Value's name), highest first or lowest first, offline players too (the save file keeps their names): Each runs once per place with Rank, Name and Value, then Then. How many places: Top Players places, in the mode's Limits settings (10 to start).

      Inputs (1)
      Run Flow
      Runs this node.
      Outputs (5)
      Each Flow
      Runs once for every item.
      Rank Number
      The place: 1 for the best.
      Name Text
      Their name as last seen (bots and LAN players: the name they were saved by).
      Value Number
      Their saved value.
      Then Flow
      Goes on when it's done.
      Settings (2)
      Saved value
      A name, as the map or the game knows it (letters, digits, _ . -). Default: wins.
      Order
      Pick one: Highest first, Lowest first. Default: high.
      Limits (1)
      Top Players places
      10 by default; hosts can raise it to 100. Above 50 the server may slow down.
      Notes (2)

      Reads every player's value of one Saved Value (its name) from the save file, so players who aren't on the server count too, named as they were last seen. Each runs once per place, best first. How many places is Top Players places, a setting in the mode's Limits group, 10 to start (the checks warn above 50).

      Cost: Goes through the whole save file each time it runs: run it now and then (a round's start, a chat command), not every tick.

      Related:Saved ValueAdd To SavedSave Value

      Made from the app's own catalog (nodes.json, nodehelp.json, limits.ts), so it matches the app.
