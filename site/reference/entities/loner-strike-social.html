    Loner-Strike: Social

    1 entity the map editor places. Pick one for its keys and flags.

    componentls_meeting_pointPlayers hold USE here to call a meeting: everyone gathers, talks and votes someone out.

    ls_meeting_point

    componentMeeting point

    Players hold USE here to call a meeting: everyone gathers, talks and votes someone out.

    A point entity. Needs Loner-Strike's components plugin, which comes with the app.

    Keys (9)
    Name targetname
    What map logic and modes call this component. A button whose target is this name sets it off.
    On at round start enabled
    Off: it does nothing until a mode or map logic switches it on. Default: 1. Choices: 1 Yes, 0 No.
    Sets off target
    What to set off when its main thing happens (taken, opened, extracted, broken...).
    Box size (x y z) size
    Use a box instead of a circle: width, depth and height in units, centered on the point.
    Radius radius
    Where players can call it from and gather around. Default: 160.
    Cooldown cooldown
    Seconds before another can be called. Default: 60.
    Who can call callers
    Who can call it: only the mode, or players too. Default: 0. Choices: 0 Any player.
    Freeze players freeze
    Players who arrive wait frozen until it ends. Default: 1. Choices: 1 Yes.
    Bring everyone here gather
    Everyone is brought to it when it's called. Default: 1. Choices: 1 Yes.

    Made from the app's own catalog (cstrike.fgd, lonerstrike.fgd, components.json), so it matches the app.
