    Loner-Strike: Creatures

    2 entities the map editor places. Pick one for its keys and flags.

    componentls_barnacleA barnacle on the ceiling (needs Loner-Strike's game DLL).componentls_creatureA creature placed in the map (needs Loner-Strike's game DLL; types from creatures.ini).

    ls_barnacle

    componentBarnacle

    A barnacle on the ceiling (needs Loner-Strike's game DLL). Put it right under the ceiling: its tongue hangs to the floor, and a player who walks into it is hauled up and chewed until someone shoots it. It comes back every round.

    A point entity. Needs Loner-Strike's components plugin, which comes with the app.

    Keys (3)
    Health health
    Shots it takes. Default: 25.
    Longest tongue length
    It hangs to the floor below, at most this far. Default: 512.
    Catches hates
    Who it catches. Default: all. Choices: all Everyone.

    ls_creature

    componentCreature

    A creature placed in the map (needs Loner-Strike's game DLL; types from creatures.ini). It comes back every round.

    A point entity. Needs Loner-Strike's components plugin, which comes with the app.

    Keys (11)
    Type type
    A type from creatures.ini (the Creature Studio makes more); any name works. Default: zombie. Choices: zombie Zombie, runner Runner, brute Brute, spitter Spitter, hound Hound, turret Turret, boss Boss, headcrab Headcrab, vortigaunt Vortigaunt, babygarg Baby gargantua, snark Snark, babycrab Baby headcrab, miniturret Mini turret, assassin Assassin, soldier Soldier, gonarch Gonarch.
    Behavior behaviour
    Empty: the type's own. Choices: idle Idle, wander Wander round its spot, patrol Patrol (a path_corner chain), guard Guard its spot, chase Hunt (always knows where you are), flee Run away.
    Patrol path path
    The first path_corner of its patrol.
    Comes back after respawn
    Seconds after it dies (0 = next round; empty: the type's).
    Speed speed
    Running speed (empty: the type's).
    Aggression aggression
    0 only fights back .. 1 attacks anyone it notices (empty: the type's).
    Attacks hates
    Who it attacks (empty: what its type usually attacks).
    Body stays persist
    Hidden until it comes back instead of removed. Default: 0. Choices: 0 No.
    Runs when hurt below flee_hp
    A share of its health (0.3 = 30 %); 0 never runs; empty: the type's.
    Tier tier
    A tougher variant: tier 2 glows yellow, tier 3 red-orange and is a little bigger (the type may give it more health). Default: 1. Choices: 1 1 (normal).
    Facing (pitch yaw roll) angles
    Default: 0 0 0.

    Made from the app's own catalog (cstrike.fgd, lonerstrike.fgd, components.json), so it matches the app.
