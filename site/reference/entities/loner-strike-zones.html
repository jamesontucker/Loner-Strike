    Loner-Strike: Zones

    3 entities the map editor places. Pick one for its keys and flags.

    componentls_damage_zoneHurts players inside: fire, poison, shock.componentls_safe_zoneThe safe circle (battle royale).componentls_zone_shrinkerShrinks a safe zone in stages: warn (next circle shown), then close in, with more damage each stage.

    ls_damage_zone

    componentDamage zone

    Hurts players inside: fire, poison, shock. Bots route around it.

    A point entity. Needs Loner-Strike's components plugin, which comes with the app.

    Keys (8)
    Name targetname
    What map logic and modes call this component. A button whose target is this name sets it off.
    On at round start enabled
    Off: it does nothing until a mode or map logic switches it on. Default: 1. Choices: 1 Yes, 0 No.
    Box size (x y z) size
    Use a box instead of a circle: width, depth and height in units, centered on the point.
    Radius radius
    How far from the middle hurts. Default: 96.
    Seconds per tick interval
    How often. Default: 1.
    Hurts team
    Who it hurts. Default: 0. Choices: 0 Everyone.
    Warning on screen hud_warning
    Shows Danger: fire while inside. Default: 1. Choices: 1 Yes.
    Red ring show
    Draw its edge for players nearby. Default: 1. Choices: 1 Yes.

    ls_safe_zone

    componentSafe zone

    The safe circle (battle royale). Players outside it take damage. Put one in the middle of the play area.

    The circle players must stay inside.

    A point entity. Needs Loner-Strike's components plugin, which comes with the app.

    Keys (4)
    Name targetname
    What map logic and modes call this component. A button whose target is this name sets it off.
    On at round start enabled
    Off: it does nothing until a mode or map logic switches it on. Default: 1. Choices: 1 Yes, 0 No.
    Radius radius
    The circle's size at round start. Default: 3000.
    Seconds per tick interval
    How often players outside are hurt. Default: 1.

    ls_zone_shrinker

    componentZone shrinker

    Shrinks a safe zone in stages: warn (next circle shown), then close in, with more damage each stage.

    A point entity. Needs Loner-Strike's components plugin, which comes with the app.

    Keys (5)
    Name targetname
    What map logic and modes call this component. A button whose target is this name sets it off.
    On at round start enabled
    Off: it does nothing until a mode or map logic switches it on. Default: 1. Choices: 1 Yes, 0 No.
    Safe zone zone
    The safe zone's Name (empty = the first one).
    Starts after start_delay
    Seconds after the round starts (-1 = when a mode starts it). Default: 30.
    Smallest radius final_r
    Never smaller than this. Default: 0.

    Made from the app's own catalog (cstrike.fgd, lonerstrike.fgd, components.json), so it matches the app.
