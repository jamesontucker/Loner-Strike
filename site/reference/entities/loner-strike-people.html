    Loner-Strike: People

    3 entities the map editor places. Pick one for its keys and flags.

    componentls_interactableAnything players use with E: a lever, a terminal, a note, a pickup.componentls_interactable_brushA brush players use with E (a lever, a console, a hatch).componentls_npcA character players talk to: press E to start a conversation (a game mode can add lines and replies).

    ls_interactable

    componentInteractable

    Anything players use with E: a lever, a terminal, a note, a pickup. Shows its prompt when looked at, then sets off its targets.

    A point entity. Needs Loner-Strike's components plugin, which comes with the app.

    Keys (9)
    Name targetname
    What map logic and modes call this component. A button whose target is this name sets it off.
    On at round start enabled
    Off: it does nothing until a mode or map logic switches it on. Default: 1. Choices: 1 Yes, 0 No.
    Team team
    Which team this is for. Default: 0. Choices: 0 Anyone, 1 Terrorists, 2 Counter-Terrorists.
    Prompt prompt
    Shown to someone looking at it from within range. Default: Press E to use.
    Cooldown cooldown
    Seconds before it can be used again. Default: 1.
    Disappears when used hide
    Gone once used (a note, a pickup); back next round. Default: 0. Choices: 0 No.
    Bots may use bots
    Bots go and use it now and then while it's usable. Default: 0. Choices: 0 No.
    Model model
    Empty: nothing drawn (an invisible switch).
    On use, sets off target
    What to set off when it's used (doors, buttons, a multi_manager...).

    ls_interactable_brush

    componentInteractable brush

    A brush players use with E (a lever, a console, a hatch). Shows its prompt when looked at, then sets off its targets. In the game it is an ls_interactable.

    A brush entity: tie brushes to it. Needs Loner-Strike's components plugin, which comes with the app.

    ls_npc

    componentNPC

    A character players talk to: press E to start a conversation (a game mode can add lines and replies). It can stand, wander, patrol or follow, and faces whoever talks to it. Bots never shoot it while it's unkillable and walk round it.

    A character players talk to with E; stands, wanders, patrols or follows.

    A point entity. Needs Loner-Strike's components plugin, which comes with the app.

    Keys (9)
    Name targetname
    What map logic and modes call this component. A button whose target is this name sets it off.
    On at round start enabled
    Off: it does nothing until a mode or map logic switches it on. Default: 1. Choices: 1 Yes, 0 No.
    Model model
    barney, gman, scientist... or any model loaded with the map. Default: models/barney.mdl.
    Patrol targets targets
    Names of entities to walk between, in order, separated by spaces.
    Follows for follow_secs
    Seconds it follows someone after a talk. Default: 10.
    Health health
    Only when it can be killed. Default: 100.
    Greeting greet
    What it says when someone starts talking.
    Talks to team
    Who can talk to it. Default: 0. Choices: 0 Anyone.
    On talk, sets off target
    What to set off when someone starts talking to it (a door, a multi_manager...).

    Made from the app's own catalog (cstrike.fgd, lonerstrike.fgd, components.json), so it matches the app.
