    Loner-Strike: Objectives

    3 entities the map editor places. Pick one for its keys and flags.

    componentls_capture_pointA point teams take by standing on it, and hold.componentls_checkpointA gate in a race.componentls_extraction_zonePlayers who stay inside long enough while it's open get out (and are done for the round).

    ls_capture_point

    componentCapture point

    A point teams take by standing on it, and hold. Bots attack and defend it.

    Stand on it to take it for your team.

    A point entity. Needs Loner-Strike's components plugin, which comes with the app.

    Keys (9)
    Name targetname
    What map logic and modes call this component. A button whose target is this name sets it off.
    On at round start enabled
    Off: it does nothing until a mode or map logic switches it on. Default: 1. Choices: 1 Yes, 0 No.
    Sets off target
    What to set off when its main thing happens (taken, opened, extracted, broken...).
    Radius radius
    How far from the middle counts as inside (units). Ignored when Box size is set. Default: 128.
    Box size (x y z) size
    Use a box instead of a circle: width, depth and height in units, centered on the point.
    Seconds to take capture_secs
    With one player on it. Default: 10.
    Decay decay
    How fast a half-taken point goes back when nobody is on it (0 = keeps progress). Default: 1.
    Held at start by start_owner
    Which team holds it at round start. Default: 0. Choices: 0 Nobody.
    Every player for themselves ffa
    Held by one player instead of a team (King of the Hill). Default: 0. Choices: 0 No.

    ls_checkpoint

    componentCheckpoint

    A gate in a race. Players pass them in order; passing the last one finishes a lap.

    Race gates passed in order.

    A point entity. Needs Loner-Strike's components plugin, which comes with the app.

    Keys (7)
    Name targetname
    What map logic and modes call this component. A button whose target is this name sets it off.
    On at round start enabled
    Off: it does nothing until a mode or map logic switches it on. Default: 1. Choices: 1 Yes, 0 No.
    Sets off target
    What to set off when its main thing happens (taken, opened, extracted, broken...).
    Radius radius
    How far from the middle counts as inside (units). Ignored when Box size is set. Default: 128.
    Box size (x y z) size
    Use a box instead of a circle: width, depth and height in units, centered on the point.
    Team team
    Which team this is for. Default: 0. Choices: 0 Anyone, 1 Terrorists, 2 Counter-Terrorists.
    Order order
    1 is the start; the highest number finishes the lap. Default: 1.

    ls_extraction_zone

    componentExtraction

    Players who stay inside long enough while it's open get out (and are done for the round).

    A point entity. Needs Loner-Strike's components plugin, which comes with the app.

    Keys (11)
    Name targetname
    What map logic and modes call this component. A button whose target is this name sets it off.
    On at round start enabled
    Off: it does nothing until a mode or map logic switches it on. Default: 1. Choices: 1 Yes, 0 No.
    Sets off target
    What to set off when its main thing happens (taken, opened, extracted, broken...).
    Radius radius
    How far from the middle counts as inside (units). Ignored when Box size is set. Default: 128.
    Box size (x y z) size
    Use a box instead of a circle: width, depth and height in units, centered on the point.
    Team team
    Which team this is for. Default: 0. Choices: 0 Anyone, 1 Terrorists, 2 Counter-Terrorists.
    Seconds to extract hold_secs
    How long a player stays inside. Default: 8.
    Closes after close_at
    Seconds after the round starts (-1 = never). Default: -1.
    Faster together shared
    Each extra player inside makes it 50% faster. Default: 0. Choices: 0 No.
    Once per round once
    Works once per round. Default: 1. Choices: 1 Yes.
    Then action
    What happens to a player who extracted. Default: spectate. Choices: spectate Out of the round (no death counted), strip Stays, weapons taken, none Nothing (the mode decides).

    Made from the app's own catalog (cstrike.fgd, lonerstrike.fgd, components.json), so it matches the app.
