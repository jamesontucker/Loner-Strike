    Loner-Strike: Doors & traps

    3 entities the map editor places. Pick one for its keys and flags.

    componentls_moving_platformTells bots about a func_train / func_plat (they wait for it and ride it) and reports when it stops and starts.componentls_timed_doorOpens, closes and locks func_doors on a timetable.componentls_trigger_trapA trap: sets off its targets (and hurts players inside) when someone walks in, or when a button or mode fires it.

    ls_moving_platform

    componentMoving platform

    Tells bots about a func_train / func_plat (they wait for it and ride it) and reports when it stops and starts.

    A point entity. Needs Loner-Strike's components plugin, which comes with the app.

    Keys (3)
    Name targetname
    What map logic and modes call this component. A button whose target is this name sets it off.
    On at round start enabled
    Off: it does nothing until a mode or map logic switches it on. Default: 1. Choices: 1 Yes, 0 No.
    Train or platform platform
    Its Name, or its brush model (*12) in a map pack.

    ls_timed_door

    componentTimed door

    Opens, closes and locks func_doors on a timetable. Players may lock it for a while. Bots go round a locked door.

    A point entity. Needs Loner-Strike's components plugin, which comes with the app.

    Keys (8)
    Name targetname
    What map logic and modes call this component. A button whose target is this name sets it off.
    On at round start enabled
    Off: it does nothing until a mode or map logic switches it on. Default: 1. Choices: 1 Yes, 0 No.
    Sets off target
    What to set off when its main thing happens (taken, opened, extracted, broken...).
    Team team
    Which team this is for. Default: 0. Choices: 0 Anyone, 1 Terrorists, 2 Counter-Terrorists.
    Door door
    The Name of the func_door / func_door_rotating (all doors with that name), or its brush model (*12) in a map pack.
    Closes after close_at
    Seconds after the round starts (-1 = never by itself). Default: -1.
    Locked until locked_until
    Players can't open it before this many seconds into the round. Default: 0.
    Seconds to lock lock_time
    How long a player holds E to lock it (seconds). Default: 3.

    ls_trigger_trap

    componentTrap

    A trap: sets off its targets (and hurts players inside) when someone walks in, or when a button or mode fires it.

    A point entity. Needs Loner-Strike's components plugin, which comes with the app.

    Keys (14)
    Name targetname
    What map logic and modes call this component. A button whose target is this name sets it off.
    On at round start enabled
    Off: it does nothing until a mode or map logic switches it on. Default: 1. Choices: 1 Yes, 0 No.
    Sets off target
    What to set off when its main thing happens (taken, opened, extracted, broken...).
    Radius radius
    How far from the middle counts as inside (units). Ignored when Box size is set. Default: 128.
    Box size (x y z) size
    Use a box instead of a circle: width, depth and height in units, centered on the point.
    Goes off fire_on
    What sets it off: a touch, or a player pressing E. Default: touch. Choices: touch When someone walks in.
    Set off by team_only
    Who walking in sets it off. Default: 0. Choices: 0 Anyone.
    Delay delay
    Seconds between being set off and going off. Default: 0.
    Rearms after rearm_secs
    Seconds (0 = once per round). Default: 5.
    Bots avoid it danger
    Bots keep away even without damage set. Default: 0. Choices: 0 No.
    Kind trap_kind
    A word for the mode (laser, crusher, alarm).
    Stays on active_secs
    Seconds it stays on once set off, hurting creatures inside (0: goes off once). Default: 0.
    Creature damage a second (share of health) creature_dps_pct
    While on, on top: 0.16 = 16 % of a creature's full health. Default: 0.16.
    Bots switch it on bots_auto
    A bot close by with money to spare pays for it when 6+ creatures are near. Default: 1. Choices: 1 Yes.

    Made from the app's own catalog (cstrike.fgd, lonerstrike.fgd, components.json), so it matches the app.
