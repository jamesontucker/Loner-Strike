    ambient_generic

    point

    Plays a sound, looping or once.

    A point entity.

    Keys (3)
    Name targetname
    What other entities call this one when they set it off.
    Sound file message
    A .wav under sound/, e.g. ambience/wind1.wav.
    Pitch pitch
    100 is normal, higher is faster and squeakier. Default: 100.

    env_beam

    point

    A beam (electric arc, rope of light) between two named entities, or from here to a random spot within its radius.

    A point entity.

    Keys (8)
    Name targetname
    What other entities call this one when they set it off.
    Starts at LightningStart
    The entity the beam starts at (blank: this one).
    Beam sprite texture
    Needed: without a sprite the beam removes itself. Default: sprites/laserbeam.spr.
    Color rendercolor
    The color (red green blue, 0 to 255 each). Default: 255 255 255.
    Seconds each strike lasts life
    0: always on. Default: 1.
    Jaggedness NoiseAmplitude
    0 straight, 255 wild. Default: 0.
    First frame framestart
    The frame of the beam's texture it starts on. Default: 0.
    Damage a second damage
    To anything the beam touches. Default: 0.
