    Loner-Strike: Upgrades

    4 entities the map editor places. Pick one for its keys and flags.

    componentls_mystery_boxA random gun for a price.componentls_perk_machineSells one perk for as long as the player lives (lost when downed).componentls_shopA shop counter: players inside press USE for a menu of priced items.componentls_upgrade_benchUpgrades the gun in hand: Mk II (+40% damage, a magazine and a half), then Mk III (+90%).

    ls_mystery_box

    componentMystery box

    A random gun for a price. Of the boxes in one group, one is out at a time; after a few uses it moves to another.

    A point entity. Needs Loner-Strike's components plugin, which comes with the app.

    Keys (8)
    Name targetname
    What map logic and modes call this component. A button whose target is this name sets it off.
    On at round start enabled
    Off: it does nothing until a mode or map logic switches it on. Default: 1. Choices: 1 Yes, 0 No.
    Team team
    Which team this is for. Default: 0. Choices: 0 Anyone, 1 Terrorists, 2 Counter-Terrorists.
    Price price
    What it costs. Default: 950.
    The rare one super
    This gun comes as a Mk II with a long magazine. Default: m249.
    Its name super_name
    The name of the rare prize it can give. Default: the Grinder.
    Group group
    Boxes in the same group take turns. Default: box.
    Bots use it bots
    Bots can buy from it. Default: 1. Choices: 1 Yes.

    ls_perk_machine

    componentPerk machine

    Sells one perk for as long as the player lives (lost when downed). Hold USE at it to buy.

    Sells one perk (Tough, Quick hands, Double tap, Quick revive, Light feet).

    A point entity. Needs Loner-Strike's components plugin, which comes with the app.

    Keys (7)
    Name targetname
    What map logic and modes call this component. A button whose target is this name sets it off.
    On at round start enabled
    Off: it does nothing until a mode or map logic switches it on. Default: 1. Choices: 1 Yes, 0 No.
    Team team
    Which team this is for. Default: 0. Choices: 0 Anyone, 1 Terrorists, 2 Counter-Terrorists.
    Perk perk
    Which perk it sells. Default: tough. Choices: tough Tough (+50% max health).
    Price price
    For a player's first perk. Default: 1500.
    Perks at most max_perks
    0 = no limit. Default: 4.
    Bots buy here bots
    Bots can buy here. Default: 1. Choices: 1 Yes.

    ls_shop

    componentShop

    A shop counter: players inside press USE for a menu of priced items. Can have a shopkeeper (Barney or the G-Man) who greets and thanks them.

    A counter where USE opens a menu of priced items, with a shopkeeper if you like.

    A point entity. Needs Loner-Strike's components plugin, which comes with the app.

    Keys (11)
    Name targetname
    What map logic and modes call this component. A button whose target is this name sets it off.
    On at round start enabled
    Off: it does nothing until a mode or map logic switches it on. Default: 1. Choices: 1 Yes, 0 No.
    Team team
    Which team this is for. Default: 0. Choices: 0 Anyone, 1 Terrorists, 2 Counter-Terrorists.
    Radius radius
    How far from the middle counts as inside (units). Ignored when Box size is set. Default: 128.
    Box size (x y z) size
    Use a box instead of a circle: width, depth and height in units, centered on the point.
    Items items
    Name|price|give|what, separated by ;. give: an item (ammo, vesthelm, hp:50, hegrenade, a weapon name) or @word for the mode to hand out. Default: Armor|650|vesthelm|kevlar + helmet; Ammo|300|ammo|refill all your guns; Medkit|500|hp:50|+50 HP.
    Price scale scale
    Prices go up by this much each wave. Default: 1.
    Gun menu line buy_menu
    A last line opening the game's buy menu (works where it's a buy zone). Default: 0. Choices: 0 No.
    Shopkeeper keeper
    barney, gman, none, or a model (loaded with the map). Default: none.
    Greeting greet
    What the shopkeeper says to someone walking in (their first 3 visits).
    Menu title title
    Empty: the Name, else Shop.

    ls_upgrade_bench

    componentUpgrade bench

    Upgrades the gun in hand: Mk II (+40% damage, a magazine and a half), then Mk III (+90%). The level stays with the gun.

    A point entity. Needs Loner-Strike's components plugin, which comes with the app.

    Keys (7)
    Name targetname
    What map logic and modes call this component. A button whose target is this name sets it off.
    On at round start enabled
    Off: it does nothing until a mode or map logic switches it on. Default: 1. Choices: 1 Yes, 0 No.
    Team team
    Which team this is for. Default: 0. Choices: 0 Anyone, 1 Terrorists, 2 Counter-Terrorists.
    Mk II price price2
    What the second upgrade costs. Default: 3000.
    Mk III from wave level3_from
    0 = any time. Default: 12.
    Mk III damage dmg3
    How much more damage the third upgrade does (1.9: 90% more). Default: 1.9.
    Bots buy here bots
    Bots can use it. Default: 1. Choices: 1 Yes.

    Made from the app's own catalog (cstrike.fgd, lonerstrike.fgd, components.json), so it matches the app.
