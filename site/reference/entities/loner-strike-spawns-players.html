    Loner-Strike: Spawns & players

    2 entities the map editor places. Pick one for its keys and flags.

    componentls_player_classA player class: health, speed, weapons, model.componentls_respawn_pointWhere players of a team (re)spawn in a mode.

    ls_player_class

    componentPlayer class

    A player class: health, speed, weapons, model. Players pick one with say /class, or a mode gives it.

    A point entity. Needs Loner-Strike's components plugin, which comes with the app.

    Keys (10)
    Team team
    Which team this is for. Default: 0. Choices: 0 Anyone, 1 Terrorists, 2 Counter-Terrorists.
    Class name name
    What the class is called in menus and in mode code. Default: Soldier.
    Health hp
    Health at spawn. Default: 100.
    Helmet helmet
    With a helmet when armor is given. Default: 1. Choices: 1 Yes.
    Speed speed
    Running speed (250 is normal with a knife). 0 keeps the weapon's own speed. Default: 0.
    Weapons weapons
    Given at spawn, separated by spaces: knife deagle ak47 vesthelm he hp:50 ... Default: knife.
    Player model model
    A model folder under models/player (terror, vip). Empty keeps the team's.
    In the class menu menu
    Players can pick it from say /class. Default: 1. Choices: 1 Yes.
    Given to everyone default
    Players of the team without a class get this one. Default: 0. Choices: 0 No.
    Bot behavior bot_profile
    A behavior profile for bots with this class (botprofiles.ini: hunter, defender ...).

    ls_respawn_point

    componentRespawn point

    Where players of a team (re)spawn in a mode. When a map has any for a team, that team spawns only at these, at a free one.

    A point entity. Needs Loner-Strike's components plugin, which comes with the app.

    Keys (5)
    Name targetname
    What map logic and modes call this component. A button whose target is this name sets it off.
    On at round start enabled
    Off: it does nothing until a mode or map logic switches it on. Default: 1. Choices: 1 Yes, 0 No.
    Team team
    Which team this is for. Default: 0. Choices: 0 Anyone, 1 Terrorists, 2 Counter-Terrorists.
    Facing angle
    Which way the player faces, seen from above. Default: 0.
    Role role
    For the Mode Kit: only players with this role spawn here.

    Made from the app's own catalog (cstrike.fgd, lonerstrike.fgd, components.json), so it matches the app.
