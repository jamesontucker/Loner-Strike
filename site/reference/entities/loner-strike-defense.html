    Loner-Strike: Defense

    ls_barricade

    componentBarricade

    A wall that can be shot or hit down and repaired (hold USE). Bots defend behind it and go round it while it stands.

    A wall that breaks and can be repaired. Wraps the selected brushes.

    A brush entity: tie brushes to it. Needs Loner-Strike's components plugin, which comes with the app.

    Keys (11)
    Name targetname
    What map logic and modes call this component. A button whose target is this name sets it off.
    On at round start enabled
    Off: it does nothing until a mode or map logic switches it on. Default: 1. Choices: 1 Yes, 0 No.
    Sets off target
    What to set off when its main thing happens (taken, opened, extracted, broken...).
    Health hp
    How much damage it takes before it breaks. Default: 500.
    Defended by team
    This team repairs it and can't damage it. Default: 2. Choices: 0 Nobody.
    Seconds per repair repair_secs
    Each repair adds a quarter of its health. Default: 3.
    Bots go round it blocks_bots
    Bots treat it as a wall while it stands. Default: 1. Choices: 1 Yes.
    Own team can damage it friendly_damage
    Its own team's shots damage it too. Default: 0. Choices: 0 No.
    Span the corridor fit
    Map packs: stretch the barricade along this axis until it meets the walls (up to 400 units each way). Without a model it's drawn as a beam fence.
    Box size (x y z) size
    Map packs: the barricade's box when it isn't a brush. Default: 64 16 80.
    Take over adopt
    Map packs: the Name or *model of an existing func_wall/func_breakable to turn into this barricade.

    ls_wave_spawner

    componentWave spawner

    Where waves of enemies come from (Last Stand). Waves are shared by every spawner on the map.

    A point entity. Needs Loner-Strike's components plugin, which comes with the app.

    Keys (10)
    Name targetname
    What map logic and modes call this component. A button whose target is this name sets it off.
    On at round start enabled
    Off: it does nothing until a mode or map logic switches it on. Default: 1. Choices: 1 Yes, 0 No.
    Sets off target
    What to set off when its main thing happens (taken, opened, extracted, broken...).
    Enemies' team team
    Dead players (bots first) of this team come back here, unless a mode spawns its own enemies. Default: 1. Choices: 1 Terrorists.
    Enemies in wave 1 wave_min
    From this spawner. Default: 4.
    Waves waves
    How many waves there are. Default: 10.
    Spread radius
    Enemies appear within this distance. Default: 64.
    Starts by itself auto
    Starts by itself after the preparation time, and the next wave after a clear. Default: 0. Choices: 0 No (a mode starts it).
    First wave after prepare
    Seconds after the round starts, when it starts by itself. Default: 30.
    Also bring back people humans
    Dead human players come back as enemies too. Default: 0. Choices: 0 No.

    Made from the app's own catalog (cstrike.fgd, lonerstrike.fgd, components.json), so it matches the app.
