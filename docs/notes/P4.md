# P4 notes (map editor: prefabs, cordon, compile)

## Requests from QA (2026-11-12, real tests; full report docs/notes/QA.md)
1. **[Medium] Compile doesn't find a WAD in the project's folder** (the Project panel shows it there): "The map lists
   texture files that aren't on this computer: regamedll_zedit.wad". Look beside the project too (and copy it in like
   other WADs wine can't see).
2. **[Low] An empty (0-byte) WAD is reported as "not on this computer"** (aim_stadium's stgswad3.wad, de_kobbl's
   gunshop.wad ship empty). Say it's empty/unreadable; live checks don't flag it either.
3. **[Low] Raw compiler text for a map with no inside**: carver1.jmf (no entities) fails with "The compiler said: Portal
   file '…prt' does not exist, cannot vis the map". Suggest "The map has no entities inside it (add a spawn)".
4. **[Low] The compile route refuses any game folder that isn't a Steam install** (`servers::client`), so dev servers
   pointed at an HLDS folder can't compile; fine for the app, worth a word in TOOLS-DEV.md.
Worked for real: Normal compile + install of a from-scratch map, leak line (.lin), cordon (also on an imported map),
ls_outpost / br_valley sources, the result loaded in HLDS and in the CS client.
