# Studio polish pass (queued 2026-11-13, user approved)

Runs after X's and X2's feature queues, together with the fresh Studio UX/UI review and the second Studio
performance audit (both assessment-only first; the user picks from their findings). Check each item doesn't
already exist under another name before building it.

- **Promote to Variable:** right-click a pin, and it becomes a variable already wired in (and Promote to Local in a Function).
- **Graph tidying:** align and distribute selected nodes, straighten wires, select linked nodes (upstream and
  downstream), and bookmarks to jump between parts of a big graph.
- **Version history:** a list of past saves with a visual diff and Restore, beyond undo.
- **Quick-add shortcuts:** B + click for Branch, S + click for Sequence, and so on, like Unreal (some shortcut code exists already).
