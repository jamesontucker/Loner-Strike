# Stock entities in the editor (EngineCoverage item 9)

Checked against the game DLL we ship (ReGameDLL `ls-next3` b1061777, `LINK_ENTITY_TO_CLASS` and each
class's `KeyValue`/spawnflags). Keys left empty are the game's own default (0 for most), so the FGD
defaults are the game's, and `editor/checks/logic.rs` flags the ones where 0 means "never".

## Added
- FGD (`editor/cstrike.fgd`): trigger_random (+ `_time`, `_unique`), trigger_setorigin, env_global,
  game_score, game_counter, game_counter_set, game_team_master, game_team_set, game_player_team (warns),
  game_player_hurt, game_zone_player, momentary_door, momentary_rot_button, button_target, path_track,
  func_tracktrain, func_traincontrols, func_vehiclecontrols, func_trackchange, func_trackautochange,
  func_platrot, func_guntarget, func_tank, func_tankmortar, func_tanklaser, func_tankcontrols,
  func_healthcharger, func_recharge, item_healthkit/battery/kevlar/assaultsuit/thighpack/longjump, the ten
  ammo_ boxes. game_text, game_player_equip, game_end get a master; game_end warns; path_corner gets its
  pass target and Fires only once.
- I/O links (`editor/io.rs`, `ioGraph.ts`): class-only link keys and trigger_random's `target0..15`.
- Checks (`editor/checks/logic.rs`): empty required keys, wrong kind on the other end, origin brushes.
- Previews (`StockPreviews.tsx`): tracks as arrows, turret aim arcs, trigger_setorigin lines; pickups as
  their models (`EntityModels.tsx`).

## Left out (the DLL has the class, but)
- func_tankrocket: fires `rpg_rocket`, which Counter-Strike doesn't have (no rockets).
- info_intermission: nothing in the CS game code reads it.
- env_lightning, env_debris: the same classes as env_beam and env_spark under another name.
- item_suit, item_antidote, item_security, item_airtank: Half-Life items with no use in CS.
- func_monsterclip, trigger_monsterjump: monster-only. cycler_weapon: a debug model viewer.
- item_airbox (ReGameDLL addon): could come later.

## Verified
- `cargo test editor::` (fgd, io, checks incl. logic), `tools::editor`.
- Real compile through the editor's compile (`real_compile_of_the_stock_entities`, SDHLT fast): clean.
- One sim (Sim/STK, ls-next3 b1061777 mp.dll, plugins fresh from tools HEAD, `-insecure`, port 27591), with a
  throwaway rcon plugin firing entities by name: every entity spawned (func_traincontrols removes itself
  after linking, as it should); trigger_random spread 4/6 over 10, unique fired each once then stopped,
  random_time fired every second, counter_set, counter limit chain, trigger_setorigin (moved onto dest +16),
  tracktrain ran its track, momentary_door to fully open, guntarget moved between corners, button_target
  on/off, platrot, zone counted a player, game_score +5 and game_player_hurt -10 on a bot, team master.
  Console: no entity errors (only the expected missing .nav, generated by the bots).
- Playwright `editor-stock-entities.spec.ts`: Chromium and WebKit, 2/2 each; editor-io and editor-checks still pass.

## Not verified
- Turrets, chargers, pickups and func_trackchange in play (need a human player); env_global's effect on a
  multisource (fired, not observed). The sim clone `Sim/STK` (1.3 GB) still needs deleting: the safety hook
  blocks `rm -rf` outside the worktree.
