## How I test
- Sim copy `Sim/X2A` (APFS clone of LSPLAY with the repo's gm_components compiled in).
- Two Tools dev servers: 8052 over X2A (Quick check, Compile), 8053 over the real game read-only with
  `LS_SERVERS_DIR=Sim/X2SRV`, `LS_TEST_RUN_SOURCE=Sim/X2A` (Test run: its hidden server is `Sim/X2SRV/.studio-test`).
- Test graphs are built by scripts in my scratchpad (graph builder + client for /validate, /check, /testrun).
