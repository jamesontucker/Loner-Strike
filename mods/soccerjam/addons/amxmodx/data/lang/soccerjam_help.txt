HELP_HEADER = Soccer Jam help
HELP_TITLE = How to play Soccer Jam
HELP_MOVES_TITLE = Moves
HELP_MOVES_KICK = Kick the ball: USE key (E). Run into the ball to pick it up.
HELP_MOVES_CURVELEFT = Curve left: radio1 key (Z) while holding the ball
HELP_MOVES_CURVERIGHT = Curve right: radio2 key (X) while holding the ball
HELP_MOVES_TURBO = Turbo sprint: drop key (G)
HELP_MOVES_UPGRADE = Upgrade menu: lastinv key (Q)
HELP_MOVES_DIVE = Dive: strafe + jump (without moving forward/back)
HELP_MOVES_CATCH = Catch a fast ball: hold USE as it reaches you
HELP_STATS_TITLE = Upgrades
HELP_STATS_STAMINA = Stamina: more health
HELP_STATS_STRENGTH = Strength: harder kicks
HELP_STATS_AGILITY = Agility: faster running
HELP_STATS_DEXTERITY = Dexterity: better catching
HELP_STATS_DISARM = Disarm: knife hits can knock the ball or knife away
HELP_POWERPLAY_TITLE = Power play
HELP_POWERPLAY_ONE = Passing between teammates raises the power play level
HELP_POWERPLAY_TWO = Higher power play makes the ball holder faster and kicks stronger
HELP_TIPS_TITLE = Tips
HELP_TIPS_ONE = The mascot near each goal zaps enemies who come too close - shoot from a distance
HELP_TIPS_TWO = Knife the ball carrier to steal the ball
HELP_TIPS_THREE = Say "spec" to spectate
